# What is Letter & Number Series?

The examiner gives you a **sequence (series)** of letters, numbers, or both.

Your job is to **find the hidden pattern** and predict the next term or the missing term.

For example,

```
2, 4, 6, 8, ?
```

Pattern:

```
+2
```

Answer:

```
10
```

---

## Types of Letter & Number Series

There are mainly **7 types**.

![](./types.png)

---

## 1. Number Series ⭐⭐⭐⭐⭐ (Most Common)

Find the next number.

Example

```
3, 6, 9, 12, ?
```

Pattern

```
+3
```

Answer

```
15
```

---

Example

```
2, 4, 8, 16, ?
```

Pattern

```
×2
```

Answer

```
32
```

---

## 2. Letter Series ⭐⭐⭐⭐⭐

Find the next letter.

Example

```
A C E G ?
```

Letters are skipping one each time.

```
A B C D E F G H I

A → C → E → G → I
```

Answer

```
I
```

---

## 3. Mixed Letter & Number Series ⭐⭐⭐⭐

Example

```
A1 B2 C3 D4 ?
```

Pattern

Letters increase.

Numbers increase.

Answer

```
E5
```

---

## 4. Alphabet Position Questions ⭐⭐⭐⭐⭐

You must know

```
A=1
B=2
C=3
...
Z=26
```

Example

```
2, 4, 6

↓

B D F
```

or

```
C F I L ?
```

Positions

```
3
6
9
12
```

Pattern

```
+3
```

Answer

```
O
```

---

## 5. Missing Term ⭐⭐⭐⭐

Example

```
5, 10, __, 20, 25
```

Pattern

```
+5
```

Answer

```
15
```

---

## 6. Wrong Number ⭐⭐⭐

Example

```
2, 4, 8, 15, 16
```

Everything doubles except 15.

Wrong number

```
15
```

---

## 7. Alternating Pattern ⭐⭐⭐⭐⭐

Very common in TCS.

Example

```
2, 5, 4, 7, 6, 9, ?
```

Split into two series.

Odd positions

```
2,4,6...
```

Even positions

```
5,7,9...
```

Answer

```
8
```

# Learning Order (Recommended)

We'll study it in this order:

1. ✅ Basic Number Series (+, −, ×, ÷)
2. ✅ Square & Cube Series
3. ✅ Prime Number Series
4. ✅ Alphabet Position
5. ✅ Letter Series
6. ✅ Mixed Letter-Number Series
7. ✅ Alternating Series
8. ✅ Missing & Wrong Term
9. ✅ Advanced Pattern Recognition (TCS/Cognizant level)

This order builds your pattern-recognition skills gradually, and by the end you'll be able to solve almost every Letter & Number Series question asked in placement exams.
