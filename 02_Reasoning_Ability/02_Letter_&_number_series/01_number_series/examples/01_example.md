This is one of the **most important questions** because it teaches you **how to think** during a series question.

# Question

```text
2, 4, 8, 14, 22, 32, ?
```

---

# Method 1 (Always Start Here)

## Check the difference

Subtract consecutive terms.

```text
4 - 2 = 2
8 - 4 = 4
14 - 8 = 6
22 - 14 = 8
32 - 22 = 10
```

So we get

```text
2, 4, 6, 8, 10
```

Now check this series.

```
2 → 4 → 6 → 8 → 10
```

Difference

```
+2
+2
+2
+2
```

Very simple.

So next difference is

```
12
```

Now

```
32 + 12 = 44
```

✅ Answer = **44**
