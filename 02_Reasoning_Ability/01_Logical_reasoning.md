Reasoning Ability is a section in aptitude tests that measures **how well you can think logically and solve problems**, rather than how much you have memorized.

Think of it this way:

* **Numerical Ability** → Can you work with numbers?
* **Verbal Ability** → Can you understand and use English?
* **Reasoning Ability** → Can you identify patterns, analyze information, and reach logical conclusions?

For example:

### 1. Number Series

Find the next number:

```
2, 4, 8, 16, ?
```

You recognize the pattern:

```
×2

2 → 4 → 8 → 16 → 32
```

**Answer:** 32

---

### 2. Coding-Decoding

If

```
CAT = DBU
```

Then

```
DOG = ?
```

Notice each letter is shifted forward by one:

```
D → E
O → P
G → H
```

**Answer:** EPH

---

### 3. Blood Relations

```
A is B's brother.
B is C's mother.

Who is A to C?
```

Since A is B's brother, and B is C's mother:

**Answer:** A is C's **maternal uncle**.

---

### 4. Direction Sense

```
A walks 10 m north,
then turns right and walks 5 m.

Which direction is A facing?
```

Facing north, turning right means:

**Answer:** East

---

### 5. Seating Arrangement

```
Five people sit in a row.

A sits left of B.
C sits right of A.
D sits at the end.

Find everyone's position.
```

These questions test your ability to organize information logically.

---

### 6. Syllogism

```
All cats are animals.
Some animals are pets.

Can we conclude:
Some cats are pets?
```

**Answer:** No.

Why? We only know:

* All cats are animals.
* Some animals are pets.

We are **not told** that any cat is among those pets.

## Is it difficult?

Not really. Unlike mathematics, reasoning usually doesn't require formulas. The key skills are:

* Observing patterns
* Thinking step by step
* Eliminating incorrect options
* Practicing regularly

The more questions you solve, the faster you become at recognizing common patterns.
