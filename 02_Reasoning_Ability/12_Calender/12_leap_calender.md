For a **leap year**, the pattern changes because February has **29 days instead of 28**.

### 🟢 Leap-year same-date groups

For any leap year:

| Group | Months                     |
| ----- | -------------------------- |
| **1** | **January = April = July** |
| **2** | **February = August**      |
| **3** | **March = November**       |
| **4** | **September = December**   |

And the **unique months** are:

\[
\boxed{\text{May, June, October}}
\]

### So memorize both:

\boxed{Jan=Oct}

\boxed{Apr=Jul}
\]

\boxed{Sep=Dec}
\]

\boxed{May,\ Jun,\ Aug}

\[
\boxed{Jan=Apr=Jul}

\[
\boxed{Mar=Nov}
\]

\[
\boxed{Sep=Dec}

Unique:

\[
\boxed{May,\ Jun,\ Oct}
\]

### 🔥 Why does it change?

Because in a leap year:

\[
Feb=29\text{ days}
\]

and:

\[
29\bmod7=1
\]

That extra **1 day** shifts every month **after February**, which changes the grouping.

## What does `February = August` actually mean?

It **does NOT mean the entire months are identical**.

It means:

> **For any date that exists in both months, the same date has the same weekday.**

So in a leap year:

* Feb 1 = Aug 1 ✅
* Feb 10 = Aug 10 ✅
* Feb 28 = Aug 28 ✅

But:

* Aug 29 ❌ no Feb 29? **Actually in a leap year Feb 29 DOES exist**, so:

  * Feb 29 = Aug 29 ✅
* Aug 30 ❌ no Feb 30
* Aug 31 ❌ no Feb 31

So the relationship is valid only for **February 1–29**.

---

### Why does this happen?

Because from the same date in February to the same date in August:

\[
29+31+30+31+30+31=182
\]

And:

\[
182=26\times7
\]

So there is **zero weekday shift**.

That's why:

\[
\boxed{\text{Feb 1–29 = Aug 1–29}}
\]

---

### 🔥 The thing to remember

When we write:

\[
\boxed{Feb=Aug}
\]

we're using a **shortcut notation**.

It really means:

> **Same valid date → same weekday.**

It does **not** mean both months have the same number of days.

So **August 30 and 31 are simply outside this pairing** because February has no such dates.
