In **any ordinary year**, if you take the **same date number**, the weekday is identical in these month groups:

### ✅ Ordinary-year fixed groups

| Group | Months                          |
| ----- | ------------------------------- |
| **1** | **January = October**           |
| **2** | **February = March = November** |
| **3** | **April = July**                |
| **4** | **September = December**        |

And the **unique months** are:

\[
\boxed{\text{May,\ June,\ August}}
\]

### Example

If **10 January = Monday**, then in the same ordinary year:

* 10 October = Monday ✅

If **10 February = Tuesday**, then:

* 10 March = Tuesday ✅
* 10 November = Tuesday ✅

If **10 April = Wednesday**, then:

* 10 July = Wednesday ✅

If **10 September = Thursday**, then:

* 10 December = Thursday ✅

And:

* May ❌ unique
* June ❌ unique
* August ❌ unique

### Why does this happen?

Because the number of days between the same dates is a multiple of 7.

For example:

**January → October:**

\[
31+28+31+30+31+30+31+31+30=273
\]

\[
273\div7=39
\]

No remainder → **same weekday**.

And this relationship is based on the month lengths, so it holds for **every ordinary year**.

⚠️ **But not for leap years**, because February changes from 28 to 29 days and shifts everything after February by 1 day.

So for your TCS shortcut, you can memorize:

\[
\boxed{Jan=Oct}
\]

\[
\boxed{Feb=Mar=Nov}
\]

\[
\boxed{Apr=Jul}
\]

\[
\boxed{Sep=Dec}
\]

\[
\boxed{May,\ Jun,\ Aug\text{ = unique}}
\]

**This is exactly the pattern you were pointing out.**
