Absolutely. These are **seating arrangement + profession matching** questions. The easiest way is **not to solve everything at once**.

Use a fixed method:

> **1. Draw the seats → 2. Put the fixed information → 3. Convert clues into restrictions → 4. Solve professions last.**

Let's do this exact question slowly.

### 1. Draw the 7 berths

There are:

* **2 lower**
* **3 middle**
* **2 upper**

So make:

```text
UPPER     U1          U2
MIDDLE   M1   M2   M3
LOWER     L1          L2
```

We don't know which person is where yet.

---

### 2. Start with the strongest clues

The question says:

> **B and F are not on the middle berth**

So:

```text
B ≠ MIDDLE
F ≠ MIDDLE
```

Therefore B and F must be in **LOWER or UPPER**.

Then:

> **A, the Engineer, is not on the upper berth.**

So A is:

```text
A = LOWER or MIDDLE
```

---

### 3. Look at this important clue

> **The Architect is the only other person who occupies the same type of berth as A.**

This is VERY important.

"Only other person" means **exactly 2 people occupy A's berth type**.

For example, if A is on a lower berth, then exactly one other person is on lower.

If A is middle, then exactly one other person is middle.

---

### 4. Use C

> **C is a Pharmacist.**

So:

```text
C → Pharmacist
```

---

### 5. Use E

> **E occupies same type of berth as the Doctor.**

So:

```text
E = same berth type as Doctor
```

---

### 6. Now use B and F's professions

> B and F's professions are **Pathologist and Lawyer respectively.**

"Respectively" means:

```text
B → Pathologist
F → Lawyer
```

This is a very important exam trick.

Remaining professions:

**Doctor, Architect, Journalist**

> G is neither a Journalist nor an Architect.

Therefore G must be:

**G → Doctor**

| Person | Profession  |
| ------ | ----------- |

| B      | Pathologist |

| D      | ?           |
| E      | ?           |
| F      | Lawyer      |
| G      | **Doctor**  |

And since:

> E occupies the same type of berth as the Doctor.

Doctor = G.

Therefore:

**E and G have the same berth type.**

### 8. Now use A + Architect clue

A = Engineer.

A is **not upper**.

The Architect is the **only other person** in A's berth type.

Remaining professions for D and E:

* Architect
* Journalist

So **either D or E is Architect**.

Now notice G = Doctor and E is in the same berth type as G.

If E were Architect, then **E and A** would have to occupy the same berth type.

But E is also same berth type as G.

That would put **A, E and G** in the same berth type.

The clue says the Architect is the **only other person** who occupies A's berth type — meaning only A + Architect can be there.

So E cannot be Architect.

Therefore:

### **D = Architect**

And hence:

# 🎯 **Answer: D is the Architect.**

## The EASY method for these questions

When you see a question like this in TCS, don't randomly try combinations.

Use this order:

### **Step 1 — Draw the categories**

```text
UPPER   : 2
MIDDLE  : 3
LOWER   : 2
```

### **Step 2 — Find direct information**

Look for words like:

* "is"
* "not"
* "respectively"
* "same as"
* "only"
* "neither/nor"

These give the strongest information.

### **Step 3 — Make a small table**

```text
Person       Profession
A            Engineer
B            Pathologist
C            Pharmacist
D            ?
E            ?
F            Lawyer
G            ?
```

### **Step 4 — Fill what can be directly eliminated**

Remaining professions → Doctor, Architect, Journalist.

G cannot be Journalist or Architect.

Therefore:

**G = Doctor**

### **Step 5 — Chain the clues**

G = Doctor
↓
E has same berth type as Doctor
↓
E has same berth type as G
↓
Architect is the only other person in A's berth type
↓
E cannot be Architect
↓
D = Architect

---

### ⭐ The biggest trick to remember

Whenever you see:

> **"X is the only other person who occupies the same type of berth as Y"**

Think immediately:

**Y + X = exactly 2 people in that berth category.**

That single phrase is usually a **very strong clue**.

And whenever you see:

> **"B and F are ... respectively"**

immediately write:

**B → first thing**
**F → second thing**

This will make these TCS-style arrangement questions much faster.
