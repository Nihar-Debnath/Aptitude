## Given meanings

The question says:

```text
− means +
+ means −
* means ÷
÷ means *
```

So make this little table:

| Symbol shown | Actually means |
| ------------ | -------------- |
| `−`          | `+`            |
| `+`          | `−`            |
| `*`          | `÷`            |
| `÷`          | `*`            |

# Check the options

We simply **replace the symbols according to the table**, then calculate.

### A

[

```text

− → +
÷ → *
```

10-5+\frac{140}{15}

This is **not 158** ❌

### D ⭐

[
30*5-4÷10+15=31
]

Replace the symbols:

```text
* → ÷
− → +
÷ → *
+ → −
```

[

[

[

[

✅ Exactly matches the RHS!

# 🎯 Answer: **D**

## 🔥 Your shortcut is excellent

For these **symbol-operation questions**, use this order:

### 1. Replace the symbols

### 2. **Check division first**

Ask:

> Does the division give an integer or decimal?

If the RHS is a whole number and your expression produces an unavoidable decimal → **eliminate immediately.**

### 3. Only calculate the surviving option(s)

Here:

| Option | After replacement | Division | Result type |            |
| ------ | ----------------- | -------- | ----------- | ---------- |
| A      | `... + 140 ÷ 15`  | Decimal  | ❌           | Eliminate  |
| B      | `... + 10 ÷ 15`   | Decimal  | ❌           | Eliminate  |
| C      | `... − 140 ÷ 15`  | Decimal  | ❌           | Eliminate  |
| D      | `30 ÷ 5`          | Integer  | ✅           | **Answer** |

So you were **100% right**: **don't waste time doing the full division.** Use **integer vs decimal → eliminate → calculate only if necessary.** 🔥
