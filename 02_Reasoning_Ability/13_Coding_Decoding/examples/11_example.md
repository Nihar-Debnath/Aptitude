This is another **name-changing / substitution** type. The easiest way is to work **backward from what the question asks**.

Question:

> If **dog** is called **lion**,
> **lion** is called **bison**,
> **bison** is called **snake**,
> **snake** is called **mongoose**,
> **mongoose** is called **crocodile**,
> then which one is reared as a pet?

Options:

* A. Lion
* B. Dog
* C. Bison
* D. Snake

### Step 1: Ask the real-world question

Which animal among the options is normally reared as a pet?

👉 **Dog**

But the question isn't asking for the *actual name* directly. It asks:

> **What is DOG called in this coded language?**

### Step 2: Find DOG's new name

Given:

```text
DOG → LION
```

So in this language:

> **Dog is called Lion.**

Therefore the answer is:

# ✅ **A. Lion**

---

### 🧠 The key trick

Don't follow the whole chain!

You don't need:

```text
DOG → LION → BISON → SNAKE → MONGOOSE → CROCODILE
```

Because the question asks:

> **Which one is reared as a pet?**

First identify the actual animal:

```text
Pet → DOG
```

Then look up what **DOG is called**:

```text
DOG → LION
```

So:

[
\boxed{\text{Lion}}
]

### 🔥 Exam shortcut

For these questions:

> **Find the real answer first → then convert its name using the given coding rule.**

You only needed **one line** here:

**Pet = DOG → DOG is called LION → Answer = LION.**
