## Step 1: Divide the given word into groups

There are 9 letters, so make groups of **3**:

```text
CATACOMBA
↓
CAT | ACO | MBA
```

Now look at the coded word:

```text
MBACATACO
↓
MBA | CAT | ACO
```

So the groups have been rearranged:

```text
Original:  CAT | ACO | MBA
             1     2     3

Code:      MBA | CAT | ACO
             3     1     2
```

### 🔥 The grouping pattern is:

> **3 → 1 → 2**

---

# Step 2: Apply the same grouping to BLACKJACK

Write it:

```text
BLACKJACK
```

It has 9 letters.

```text
BLA | CKJ | ACK
```

Now follow the same **3 → 1 → 2** pattern:

```text
3 = ACK
1 = BLA
2 = CKJ
```

Therefore:

```text
ACK | BLA | CKJ
```

Join them:

# ✅ **ACKBLACKJ**

## 🧠 Remember the method

Whenever the word is being **grouped/rearranged**:

### 1. Count the letters

### 2. Divide into equal groups

### 3. Divide the coded word into the same groups

### 4. Find the group order

### 5. Apply that order to the new word

Here:

```text
CAT | ACO | MBA
 ↓     ↓     ↓
 1     2     3

MBA | CAT | ACO
 3     1     2
```

So the rule is:

[
\boxed{3-1-2}
