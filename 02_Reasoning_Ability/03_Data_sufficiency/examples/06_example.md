Excellent! This is a **Data Sufficiency + Coding-Decoding** question.

Many students get confused because they start trying to decode the language. **Don't do that.**

Remember:

> **This is NOT a Coding-Decoding question.**
>
> **It is a Data Sufficiency question.**

Your job is **not** to find the code immediately.

Your job is to ask:

> **Can I find the code for "sky"?**

Let's solve it.

---

# Question

```text
What is the code for "sky"?
```

We need to find only one word:

```text
sky = ?
```

---

# Statement I

```text
"sky is clear"

↓

"de ra fa"
```

Let's make a table.

| English | Code |
| ------- | ---- |
| sky     | ?    |
| is      | ?    |
| clear   | ?    |

Codes:

```text
de
ra
fa
```

Can we tell which one is "sky"?

No.

It could be

```text
sky = de
```

or

```text
sky = ra
```

or

```text
sky = fa
```

Three possibilities.

❌ Statement I is NOT sufficient.

---

# Statement II

```text
"make it clear"

↓

"de ga jo"
```

Table

| English | Code |
| ------- | ---- |
| make    | ?    |
| it      | ?    |
| clear   | ?    |

Codes

```text
de
ga
jo
```

Again,

Can we find "sky"?

No.

The word "sky" isn't even here.

❌ Statement II is NOT sufficient.

---

# Step 3: Combine Both Statements

Now use both.

Statement I

```text
sky is clear

↓

de ra fa
```

Statement II

```text
make it clear

↓

de ga jo
```

Now look for the **common word**.

English

```text
clear
```

appears in both.

Now look for the **common code**.

Codes

Statement I

```text
de
ra
fa
```

Statement II

```text
de
ga
jo
```

Common code

```text
de
```

So

```text
clear = de
```

Great!

---

Now remove "clear".

Statement I becomes

| English | Code |
| ------- | ---- |
| sky     | ?    |
| is      | ?    |

Remaining codes

```text
ra
fa
```

Can we tell which one is "sky"?

No.

It could be

```text
sky = ra
```

or

```text
sky = fa
```

Still two possibilities.

---

# Final Decision

| Statement | Sufficient? |
| --------- | ----------- |
| I         | ❌ No        |
| II        | ❌ No        |
| Together  | ❌ No        |

Answer

✅ **Option D**

> **Neither I nor II is sufficient.**

---

# Why isn't it Option C?

Many students think:

> "We used both statements, so it must be C."

No.

Remember:

**Option C means**

> After combining both statements, you **must be able to answer the question completely.**

Here, after combining:

```text
clear = de
```

But

```text
sky = ra OR fa
```

We still don't know.

So combining **did not solve the question**.

Therefore,

❌ Not C

✅ D

---

# The Shortcut for Coding-Decoding Data Sufficiency

Whenever you see this type of question:

### Step 1

Write both sentences as tables.

Example:

| Sentence | English       |
| -------- | ------------- |
| 1        | sky is clear  |
| 2        | make it clear |

---

### Step 2

Find the common English word.

```text
clear
```

---

### Step 3

Find the common code.

```text
de
```

---

### Step 4

Match them.

```text
clear = de
```

---

### Step 5

Delete them.

Now see whether the required word becomes unique.

If yes → Sufficient.

If no → Not sufficient.

---

## A Small Change That Would Make the Answer Option C

Suppose Statement II were:

```text
"sky make"

↓

"ra jo"
```

Now combine with Statement I:

Statement I:

```text
sky is clear

↓

de ra fa
```

Statement II:

```text
sky make

↓

ra jo
```

We still don't know everything, but now **`ra` is the only code that appears with `sky` across the information**, so we can conclude:

```text
sky = ra
```

In that case, **both statements together would be sufficient**, and the answer would be **Option C**.

---

### The key idea to remember

For **Coding-Decoding Data Sufficiency**, you're not trying to decode the entire language. You're only asking:

> **"Do I have enough information to identify the code for the specific word asked in the question?"**

If even one possibility remains, the information is **not sufficient**.
