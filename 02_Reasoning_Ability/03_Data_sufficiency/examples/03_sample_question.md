# Question

```text
Is X a prime number?
```

Again, we only need to answer:

> **Can I definitely say YES or NO?**

---

# Step 1: Check Statement I ONLY

Statement I:

```text
X = 2
```

Ignore Statement II completely.

Question:

> Is X a prime number?

Since

```text
X = 2
```

And 2 is prime.

You can confidently answer:

```text
YES
```

So,

✅ **Statement I is sufficient.**

---

# Step 2: Forget Statement I

Now imagine Statement I never existed.

Look only at Statement II.

```text
X = 2 or 4
```

This means X has **two possible values**.

### Case 1

```text
X = 2
```

Answer:

```text
YES
```

because 2 is prime.

---

### Case 2

```text
X = 4
```

Answer:

```text
NO
```

because 4 is not prime.

---

Now ask yourself:

Can I answer the question with certainty?

No.

Because sometimes the answer is **YES**, and sometimes it is **NO**.

So,

❌ **Statement II is NOT sufficient.**

---

# Final Decision

| Statement | Sufficient? |
| --------- | ----------- |
| I         | ✅ Yes       |
| II        | ❌ No        |

Therefore,

✅ **Answer = Option A**

> **Statement I alone is sufficient.**

---

# The Most Important Rule of Data Sufficiency

Whenever a statement gives **multiple possibilities**, test **every possibility**.

If **all possibilities lead to the same answer**, the statement is sufficient.

If **even one possibility changes the answer**, the statement is **not** sufficient.

### Example 1

```text
X = 2 or 3
```

Possible values:

* 2 → Prime ✅
* 3 → Prime ✅

Both cases give the same answer (**YES**).

So this statement **is sufficient**.

---

### Example 2

```text
X = 2 or 4
```

Possible values:

* 2 → Prime ✅
* 4 → Not Prime ❌

The answer changes.

So this statement is **not sufficient**.

---

## Here's a shortcut you can use in every Data Sufficiency question

Whenever you see words like:

* **or**
* **either**
* **one of**
* **could be**
* **possibly**

immediately think:

> **"I need to check every possible case."**

If all cases produce the **same final answer**, the statement is sufficient.

If different cases produce different answers, it is not sufficient.

This single rule solves a large number of Data Sufficiency questions.
