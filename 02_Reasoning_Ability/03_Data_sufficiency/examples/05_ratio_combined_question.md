Yes, **this is also a Data Sufficiency question.**

The only difference is that the topic used inside the question is **Ratio**.

> **Chapter = Data Sufficiency**
>
> **Math Topic = Ratio**

Data Sufficiency questions can come from **any math chapter**.

---

# Let's understand the question first

Question:

```text
Nibba : Nibbi = 4 : 3

What is Nibba's salary?
```

The ratio tells us

Suppose

```text
Nibba = 4x

Nibbi = 3x
```

where **x is unknown**.

Right now,

Can you find Nibba's salary?

❌ No.

Because x is unknown.

---

## Statement I

```text
Nibbi's salary is 75% of Nibba's salary.
```

Let's translate this.

75%

=

```text
75/100

=

3/4
```

So

```text
Nibbi = (3/4) × Nibba
```

But wait...

The original question already says

```text
Nibba : Nibbi = 4 : 3
```

which also means

```text
Nibbi = (3/4) × Nibba
```

So Statement I is **just repeating the same information** in a different way.

It gives **nothing new**.

Therefore

❌ Statement I is **not sufficient**.

---

## Statement II

```text
Nibbi's salary = ₹4500
```

Now use the ratio.

We know

```text
Nibba : Nibbi

=

4 : 3
```

Nibbi's 3 parts = ₹4500

So

1 part

```text
4500 ÷ 3

=

1500
```

Nibba

```text
4 × 1500

=

₹6000
```

Can we find Nibba's salary?

✅ Yes.

So Statement II alone is sufficient.

---

# Final Decision

| Statement | Sufficient? |
| --------- | ----------- |
| I         | ❌ No        |
| II        | ✅ Yes       |

Answer

✅ **Option B**

> **Statement II alone is sufficient while Statement I alone is not.**

---

# The Important Concept This Question Teaches

This question is testing whether you can identify **new information** versus **repeated information**.

Many students see Statement I and think:

> "Oh, there's another statement, so it must help."

But it doesn't.

Compare them.

### Given in the question

```text
4 : 3
```

means

```text
Nibbi

=

3/4 × Nibba

=

75%
```

### Statement I

```text
Nibbi = 75% of Nibba
```

It's exactly the same fact.

So Statement I adds **zero** information.

---

# A Quick Trick for Ratio Data Sufficiency

If the question already gives:

```text
A : B = 4 : 3
```

and a statement says

```text
B is 75% of A
```

or

```text
A is 4/3 of B
```

or

```text
A/B = 4/3
```

all of these are **equivalent**.

They don't help because they don't introduce any new information.

---

## The Golden Rule for Ratio Data Sufficiency

Whenever the question gives a ratio:

```text
A : B = m : n
```

Immediately write:

```text
A = mx

B = nx
```

Then ask yourself:

> **Does the statement help me find x?**

* If **yes**, the statement is sufficient.
* If **no**, it is not.

In this question:

* Statement I doesn't help find **x**.
* Statement II tells you **3x = 4500**, so you can find **x** and then both salaries.

That's why **Option B** is correct.
