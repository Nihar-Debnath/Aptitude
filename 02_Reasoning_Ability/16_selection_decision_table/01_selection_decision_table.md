In **Reasoning Ability**, a **Selection Decision Table** is a type of question where you are given:

* A set of **people/items/candidates**
* Some **conditions/rules** for selecting them
* You have to decide **who should be selected and who should not be selected**.

Think of it as a **filtering problem**.

### Simple example

Suppose a company wants to select candidates.

Rules:

1. Age must be **18–25**
2. Marks must be **60% or above**
3. Candidate must have **computer knowledge**

Now you get:

| Candidate | Age | Marks | Computer Knowledge |
| --------- | --: | ----: | ------------------ |
| A         |  20 |   75% | Yes                |
| B         |  27 |   80% | Yes                |
| C         |  22 |   55% | Yes                |
| D         |  24 |   70% | No                 |

We check each person against **ALL conditions**:

* **A** → 20 ✅, 75% ✅, Yes ✅ → **Selected**
* **B** → Age 27 ❌ → **Rejected**
* **C** → Marks 55% ❌ → **Rejected**
* **D** → Computer knowledge No ❌ → **Rejected**

So:

**A is selected.**

---

### Why is it called a "decision table"?

Because you're basically making a table like:

| Condition          | A          | B          | C          | D          |
| ------------------ | ---------- | ---------- | ---------- | ---------- |
| Age condition      | ✅          | ❌          | ✅          | ✅          |
| Marks condition    | ✅          | ✅          | ❌          | ✅          |
| Computer condition | ✅          | ✅          | ✅          | ❌          |
| **Decision**       | **Select** | **Reject** | **Reject** | **Reject** |

The table helps you **systematically apply the rules** instead of trying to do everything in your head.

### The important thing to understand

These questions usually contain words like:

* **must**
* **only if**
* **provided that**
* **unless**
* **either...or**
* **both**
* **at least**
* **not more than**
* **if...then**

And **these conditions are the real difficulty**.

For example:

> A candidate will be selected **if he has either a degree or 2 years of experience, but he must have computer knowledge.**

This means:

**(Degree OR 2 years experience) AND Computer knowledge**

That's where selection-decision-table questions become tricky.

If you're starting this topic from zero, I would learn it in this order:

**1. Understand conditions → 2. Understand AND/OR → 3. Understand IF/THEN → 4. Learn "unless" → 5. Solve selection tables.**
