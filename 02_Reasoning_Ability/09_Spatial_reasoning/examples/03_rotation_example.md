# There question or shapes always rotates only in clockwise direction

Yes bro — **this is exactly the kind of question where eliminating options first is much faster.** And this one has a beautiful trick.

Forget formulas. We only need to understand what **rotation does**:

> **Everything rotates together by the same amount — including the black dot.**

So let's use the **black dot as our anchor**.

---

# Step 1: Look at the original

The black dot is here:

```text
        ●
        |
        |
      ( O )
```

It's at the **TOP**.

So when the whole figure rotates, the black dot must also rotate.

---

# Step 2: Check the black dot in each option

### Option A

Dot is at the **BOTTOM**.

So this would mean the whole figure rotated:

[
180^\circ
]

### Option B

Dot is at the **bottom-left**.

So the figure rotated roughly:

[
120^\circ \text{ clockwise}
]

### Option C

Dot is at the **LEFT**.

So the figure rotated:

[
90^\circ \text{ anticlockwise}
]

### Option D

Dot is at the **bottom-right**.

So the figure rotated:

[
120^\circ \text{ anticlockwise}
]

**But we don't know yet which rotation is correct.**

So now we use **one symbol** to eliminate.

---

# Step 3: Use the BLACK TRIANGLE

This is our second anchor.

In the original:

👉 **black triangle is on the LEFT** and points **RIGHT**.

```text
          ●

     ▲?          ← no

       ◀? 
```

More simply:

**Original black triangle:**

📍 LEFT side
➡️ pointing RIGHT

Now let's see where it should go under each option's rotation.

---

# Option A ❌

A means **180° rotation**.

If we rotate the black triangle 180°:

* LEFT → RIGHT
* pointing RIGHT → pointing LEFT

So the black triangle should be:

👉 **RIGHT side, pointing LEFT**

But Option A has the black triangle at the **TOP-RIGHT**.

❌ Doesn't match.

### Eliminate A.

---

# Option B ❌

B means about **120° clockwise**.

Take the original black triangle:

**LEFT → TOP-RIGHT**

So we'd expect the black triangle around the **top-right**.

But Option B has it at **TOP-LEFT**.

❌ Doesn't match.

### Eliminate B.

---

# Option C ❌

C means **90° anticlockwise**.

Original black triangle:

**LEFT → BOTTOM**

So it should move to the **BOTTOM**.

But C has the black triangle at the **TOP**.

❌ Doesn't match.

### Eliminate C.

---

# Option D ✅

D means about **120° anticlockwise**.

Original black triangle:

**LEFT → BOTTOM-RIGHT**

And look at D:

👉 Black triangle is at **TOP-RIGHT** though? Wait—this is where the **orientation/sector reading** gets tricky from the photo.

So instead of relying on the triangle alone, use the **entire sequence of symbols**.

The original clockwise order is:

**Square → Oval → Hollow Triangle → Hollow Star → Black Star → Black Triangle**

Option D clockwise gives:

**Black Star → Black Triangle → Square → Oval → Hollow Triangle → Hollow Star**

That's exactly the original sequence shifted by **2 sectors**.

So every symbol has moved consistently by the same amount.

And the **black dot has also moved to the corresponding position**.

Therefore:

# ✅ Answer = D

---

## 🔥 But here's the TCS trick I want you to remember

For these **rotation figure questions**, don't start comparing every shape.

Do this:

### **STEP 1 — Find an anchor**

Usually the **black dot**.

### **STEP 2 — See where the dot went**

This tells you the possible rotation.

### **STEP 3 — Check ONE unique object**

For example:

* black triangle
* black star
* square

### **STEP 4 — If that object doesn't land where it should → eliminate.**

You can often eliminate **3 out of 4 options in seconds.**

### And the biggest rule:

> **Rotation moves EVERYTHING together.**

The dot, stars, triangles, squares — **all of them rotate by the exact same angle.**

That's why the dot is so useful.
