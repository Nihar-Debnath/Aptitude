## What is Scaling?

**Scaling = making a shape bigger or smaller.**

Imagine a triangle:

```text
   /\
  /  \
 /____\
```

If we make it **2 times bigger**:

```text
      /\
     /  \
    /    \
   /______\
```

The shape is still the **same shape**, but its size changed.

That's **scaling**.

---

### The main idea

With translation, we **move** the shape.

With scaling, we **resize** the shape.

| Transformation | What happens?    |
| -------------- | ---------------- |
| Translation    | Move             |
| Scaling        | Bigger / smaller |

---

## How does scaling work on coordinates?

Suppose we have:

\[
A=(2,3)
\]

and the question says **scale by 2**.

We multiply **both coordinates by 2**:

\[
(2,3)\rightarrow(2\times2,3\times2)
\]

\[
\boxed{(4,6)}
\]

So:

\[
\boxed{(x,y)\rightarrow(2x,2y)}
\]

---

### If scale = 3

\[
(x,y)\rightarrow(3x,3y)
\]

Example:

\[
(2,3)\rightarrow(6,9)
\]

The point gets **3 times farther from the origin**.

---

### If scale = ½

Now we're making it smaller:

\[
(x,y)\rightarrow\left(\frac{x}{2},\frac{y}{2}\right)
\]

Example:

\[
(4,6)\rightarrow(2,3)
\]

So:

**Scale > 1 → bigger**

**Scale between 0 and 1 → smaller**

---

### 🧠 One thing to remember

If the question says:

> **Scale by 2**

Think:

> **Multiply every coordinate by 2.**

If it says:

> **Scale by 3**

Think:

> **Multiply every coordinate by 3.**

So the basic rule is:

\[
\boxed{(x,y)\rightarrow(kx,ky)}
\]

where **k = scaling factor**.

And unlike translation, scaling usually happens **relative to the origin (0,0)** unless the question specifically says otherwise.
