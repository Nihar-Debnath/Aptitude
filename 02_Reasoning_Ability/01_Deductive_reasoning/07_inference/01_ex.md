This is a **truth-and-lie puzzle**. The easiest way is to make a small table. Don't try to mentally juggle all the statements.

We have **5 people**:

```text
Uma      → "1 of us is lying"
David    → "2 of us are lying"
Thara    → "3 of us are lying"
Querishi → "4 of us are lying"
Chitra   → "All 5 are lying"
```

The key idea:

> If someone is telling the truth, their number must equal the **actual number of liars**.

---

### Let's test the possibilities

#### Suppose there is 1 liar

Then:

```text
Actual liars = 1

Uma      → TRUE
David    → FALSE
Thara    → FALSE
Querishi → FALSE
Chitra   → FALSE
```

But that gives us **4 liars**, not 1. ❌

So impossible.

---

#### Suppose there are 2 liars

Only David's statement would be true:

```text
Actual liars = 2

Uma      → FALSE
David    → TRUE
Thara    → FALSE
Querishi → FALSE
Chitra   → FALSE
```

That's actually **4 liars**, not 2. ❌

Impossible.

---

#### Suppose there are 3 liars

```text
Uma      → FALSE
David    → FALSE
Thara    → TRUE
Querishi → FALSE
Chitra   → FALSE
```

Again, **4 people are lying**, not 3. ❌

---

#### Suppose there are 4 liars

```text
Uma      → FALSE
David    → FALSE
Thara    → FALSE
Querishi → TRUE
Chitra   → FALSE
```

Now exactly **4 people are lying**! ✅

Everything matches perfectly.

---

#### Suppose there are 5 liars

Chitra says:

> "All of us are lying."

But if Chitra is lying, then her statement is false, meaning **not everyone is lying**.

Contradiction. ❌

---

# ✅ Answer: **Querishi**

Visualize the final situation:

```text
          5 PEOPLE

Uma       ❌ Lying
David     ❌ Lying
Thara     ❌ Lying
Querishi  ✅ TRUTH
Chitra    ❌ Lying

        ↓

Exactly 4 people are lying
```

So **Querishi is the only one telling the truth.**

### 🔥 The shortcut

Because **only one statement can be true**, if that one person tells the truth, the other **4 people must be lying**.

Therefore, look for the person whose statement says:

> **"Exactly 4 of us are lying."**

That's **Querishi**. ✅
