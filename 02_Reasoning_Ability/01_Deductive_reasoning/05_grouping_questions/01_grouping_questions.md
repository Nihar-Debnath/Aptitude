# What are Grouping Based Questions?

In these questions, you are given **different items or people**, and you have to decide **which belong together (same group)** and which one does not.

Think of it as:

```text
Objects/People
        ↓
Find the common category
        ↓
Group them correctly
```

The entire question tests your ability to **classify** things.

---

# Example 1

Find the odd one.

* Apple
* Mango
* Banana
* Carrot

### Solution

Apple → Fruit

Mango → Fruit

Banana → Fruit

Carrot → Vegetable

So,

❌ Carrot is different.

---

# Example 2

Which group belongs together?

* Doctor
* Nurse
* Hospital
* Pilot

Doctor → Hospital

Nurse → Hospital

Hospital → Same field

Pilot → Aviation

So Pilot doesn't belong.

# Types of Grouping Questions

---

## Type 1: Odd One Out

Find the different item.

Example

* Tiger
* Lion
* Leopard
* Eagle

Tiger → Animal

Lion → Animal

Leopard → Animal

Eagle → Bird

Odd = Eagle

---

## Type 2: Find the Similar Group

Example

Which two are alike?

* Rose
* Lotus
* Lily
* Wheat

Rose, Lotus, Lily → Flowers

Wheat → Crop

---

## Type 3: Classification

Example

Which does NOT belong?

* CPU
* Keyboard
* Mouse
* Printer

CPU, Keyboard, Mouse → Core computer components

Printer → Peripheral device

---

## Type 4: Pair Grouping

Example

Find the related pair.

* Doctor : Hospital
* Teacher : School
* Pilot : Airport

All follow the same relationship.

---

# How to Solve

### Step 1

Look for the common category.

Ask:

> What are these?

---

### Step 2

See whether all belong to one group.

---

### Step 3

Find the item that breaks the pattern.

---

# Common Traps

### Trap 1

Very close meanings.

Example

* Dog
* Cat
* Cow
* Tiger

All are animals.

But maybe

Dog, Cat, Cow → Domestic

Tiger → Wild

---

### Trap 2

Multiple categories.

Example

* Rose
* Lotus
* Mango
* Lily

Three flowers

One fruit

---

### Trap 3

Scientific classification.

Example

* Whale
* Dolphin
* Shark
* Seal

Many think all live in water.

Actually

Whale → Mammal

Dolphin → Mammal

Seal → Mammal

Shark → Fish

Odd = Shark

---

# TCS Trick

Don't look at the words first.

Look for the **hidden category**.

Example

```
Apple
Banana
Orange
Potato
```

Don't think about food.

Think:

Fruit?

Vegetable?

Immediately you'll find the answer.

# Is this the "Grouping Based" asked in Deductive Reasoning?

There are **two different meanings** of "Grouping Based":

### 1. Classification / Odd One Out (what I explained above)

These are simple grouping questions.

---

### 2. Grouping of Statements (more common in **Deductive Reasoning**)

Example:

```
Statements:

1. All roses are flowers.
2. Some flowers are red.
3. No red thing is plastic.

Choose which statements belong to the same chain of reasoning.
```

or

```
Group I:
Statement + Assumption

Group II:
Statement + Course of Action

Group III:
Statement + Conclusion
```

These are called **grouping-based deductive reasoning questions** in many TCS coaching classes.
