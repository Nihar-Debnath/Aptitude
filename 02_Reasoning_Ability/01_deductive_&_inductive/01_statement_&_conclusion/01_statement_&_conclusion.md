Excellent choice! **Statement & Conclusion** is one of the most common reasoning topics in placement exams. The good news is that once you understand the rules, many questions become straightforward.

---

# What is Statement & Conclusion?

You'll be given:

1. **A statement** (a fact or information).
2. **One or more conclusions**.

Your job is to decide:

> **Does the conclusion logically follow from the statement?**

The important word is **logically**.

You should **only use the information given in the statement**.

❌ Do **not** use:

* Your general knowledge
* Personal opinions
* Real-world assumptions

---

# Example 1

### Statement

```text
All dogs are animals.
Tommy is a dog.
```

### Conclusion

```text
Tommy is an animal.
```

### Analysis

```
Dog ⊂ Animal

Tommy ∈ Dog

Therefore,

Tommy ∈ Animal
```

✅ The conclusion follows.

---

# Example 2

### Statement

```text
All birds can fly.
A pigeon is a bird.
```

### Conclusion

```text
A pigeon can fly.
```

From the **statement alone**, yes.

Even though in real life some birds (like ostriches and penguins) can't fly, you must accept the statement as true for the purpose of the question.

✅ Conclusion follows.

---

# Example 3

### Statement

```text
Some students are athletes.
```

### Conclusion

```text
All students are athletes.
```

Let's visualize it:

```
Students ○○○○○
           ◉◉
Athletes ○○○○○
```

"Some" means **at least one**, not **all**.

❌ The conclusion does **not** follow.

---

# Example 4

### Statement

```text
Some students are athletes.
```

### Conclusion

```text
Some students are athletes.
```

This is exactly what the statement says.

✅ Conclusion follows.

---

# Example 5

### Statement

```text
No cats are dogs.
```

### Conclusion

```text
Some cats are dogs.
```

The statement says the two groups never overlap.

```
Cats      Dogs

○○○○     ○○○○

(No overlap)
```

❌ The conclusion does not follow.

# The Four Most Important Words

Understanding these words is the key to solving these questions.

## 1. All

```
All A are B
```

Picture it like this:

```
B

┌─────────────┐
│   A A A A   │
└─────────────┘
```

Every A is inside B.

---

## 2. Some

```
Some A are B
```

Means **at least one** A is also B.

```
A ○○◉◉

     ◉◉○○ B
```

It does **not** mean all.

---

## 3. No

```
No A are B
```

```
A ○○○○

       B ○○○○
```

No overlap at all.

---

## 4. Some are not

```
Some A are not B
```

```
A ○○◉◉

B     ○○○○
```

At least one A exists outside B.

---

# Rules You Must Remember

## Rule 1

Accept the statement as completely true.

Even if it sounds unrealistic.

---

## Rule 2

Never use outside knowledge.

Question:

```
All fish live on trees.
Goldfish is a fish.
```

Conclusion:

```
Goldfish lives on trees.
```

Although it's absurd in real life, according to the given statements:

✅ The conclusion follows.

---

## Rule 3

Do not assume extra information.

Statement:

```
Some boys are intelligent.
```

Conclusion:

```
Some intelligent people are boys.
```

This follows because "Some boys are intelligent" and "Some intelligent people are boys" describe the same overlap.

---

Statement:

```
Some boys are intelligent.
```

Conclusion:

```
All intelligent people are boys.
```

❌ Does not follow.

---

# Typical Answer Options

Most exams use these patterns:

### Option A

Only Conclusion I follows.

---

### Option B

Only Conclusion II follows.

---

### Option C

Both conclusions follow.

---

### Option D

Neither conclusion follows.

# Practice Questions

## Question 1

Statement

```
All roses are flowers.
```

Conclusions

```
I. Some flowers are roses.

II. All flowers are roses.
```

Answer:

* I → ✅ Follows
* II → ❌ Does not follow

Correct option: **Only I follows.**

---

## Question 2

Statement

```
Some teachers are writers.
```

Conclusions

```
I. Some writers are teachers.

II. All teachers are writers.
```

Answer:

* I → ✅ Follows
* II → ❌ Does not follow

Correct option: **Only I follows.**

---

## Question 3

Statement

```
No doctors are engineers.
```

Conclusions

```
I. Some engineers are doctors.

II. No engineer is a doctor.
```

Answer:

* I → ❌ Does not follow
* II → ✅ Follows

Correct option: **Only II follows.**

---

# Common Mistakes

Avoid these pitfalls:

* ❌ Treating **some** as **all**
* ❌ Using real-world knowledge instead of the statement
* ❌ Assuming facts that aren't given
* ❌ Confusing **some** with **only some**
* ❌ Reading more into the statement than it actually says

---

# A Quick Trick

Whenever you see words like **All**, **Some**, or **No**, draw a simple diagram of the sets. It often makes the answer obvious and helps avoid logical mistakes.

---

## One important note

In many placement exams (including TCS, Cognizant, Infosys, and Wipro), **Statement & Conclusion** questions often appear **without** words like *All*, *Some*, or *No*. Instead, they use everyday statements, such as:

> "The government has increased the tax on tobacco products."

Then they ask which conclusion logically follows.

Those questions require a slightly different way of thinking—focusing on what is **definitely supported** by the statement and avoiding assumptions. Once you're comfortable with these basic logical rules, we can move on to those company-style questions, which are the ones you're most likely to face.
