## HVS Trick

Break the figure into **three types of straight lines**:

* **H** = Horizontal lines (—)
* **V** = Vertical lines (|)
* **S** = Slant/Diagonal lines (/ or )

Then:

1. Count all **Horizontal (H)** lines.
2. Count all **Vertical (V)** lines.
3. Count all **Slant (S)** lines.
4. Add them together.

---

### Example (Your Image)

```text id="p78bdc"
H = 1
V = 1
S = 1
```

Total:

```text id="6cq8s0"
1 + 1 + 1 = 3
```

✅ **Answer = 3 Straight Lines**
