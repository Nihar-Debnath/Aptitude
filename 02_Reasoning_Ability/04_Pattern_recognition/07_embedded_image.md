Excellent! The next topic is **Embedded Images** (also called **Embedded Figures** or **Hidden Figures**).

This is a **non-verbal reasoning** topic that appears in exams like **TCS, Infosys, Capgemini, Wipro, Cognizant, Accenture**, and many government exams.

---

# What is an Embedded Image?

An **embedded image** is a small figure that is **hidden inside a larger, more complex figure**.

Your task is:

> **Find the exact small figure inside the given large figure.**

Imagine a game of **"Find the Hidden Object."**

For example:

```
Target Figure

△
```

Large Figure

```
   /\
  /__\
 /|  |\
/_|__|_\
```

The triangle (△) is hidden inside the larger figure.

---

# Objective

You are given:

* One **simple figure** (question figure)
* One **complex figure** (answer figure)

You must determine whether the simple figure exists **exactly** inside the complex figure.

---

# Basic Rule

The figure must be **identical**.

Only its **position** may change.

It may be:

* Rotated ✅
* Hidden among other lines ✅

But it **cannot** be:

* Broken into separate pieces ❌
* Missing a line ❌
* Have an extra line as part of the target shape ❌
* Stretched or compressed ❌

# Rotation is Allowed

This is one of the most important rules.

Suppose the target is

```
L
```

Inside the big figure it appears like

```
┐
```

This is simply the same shape rotated.

It is still the correct answer.

---

Example

Target

```
└
```

Large Figure

```
┐
```

Rotate the target 180°.

It matches.

---

# Reflection (Mirror Image) is NOT Allowed

This confuses many students.

Suppose the target is

```
└
```

Large figure contains

```
┘
```

This is **not rotation**.

It is a mirror image.

Unless the question explicitly allows mirror images, the answer is **No**.

---

# Extra Lines are Allowed

Suppose the target is

```
+
```

Large figure

```
*******
***+***
*******
```

The '+' is still present.

Extra surrounding lines do not matter.

You only need to trace the required figure.

---

# Step-by-Step Method

Whenever you solve an Embedded Image question:

### Step 1

Observe the target carefully.

Count:

* Corners
* Lines
* Curves
* Angles

---

### Step 2

Notice unique features.

Example

```
└
```

It has:

* One vertical line
* One horizontal line
* One right angle

---

### Step 3

Search the larger figure slowly.

Don't look at everything at once.

Start from:

* Top-left
* Top-right
* Center
* Bottom-left
* Bottom-right

---

### Step 4

Rotate the target mentally.

Try:

* 90°
* 180°
* 270°

---

### Step 5

Ignore unnecessary lines.

Only trace the required figure.

# Common Mistakes

### Mistake 1

Ignoring rotation.

Always rotate mentally.

---

### Mistake 2

Accepting mirror images.

Mirror images are **not** the same as rotations.

---

### Mistake 3

Ignoring missing lines.

Every required line must exist.

---

### Mistake 4

Getting distracted by extra lines.

Extra lines are normal.

Focus only on the required figure.

# Quick Solving Strategy

Whenever you see an Embedded Image question, remember this checklist:

✅ Count the number of lines and corners in the target figure.
✅ Look for distinctive angles or curves.
✅ Rotate the target mentally (90°, 180°, 270°).
✅ Ignore extra lines—they don't matter.
✅ Ensure **every required line is present**.
❌ Don't accept mirror images unless the question specifically asks for them.

---

## Embedded Image vs Mirror Image

Many students confuse these two topics.

| Embedded Image                              | Mirror Image                                |
| ------------------------------------------- | ------------------------------------------- |
| Find a hidden figure inside a larger figure | Find the reflection of a figure in a mirror |
| Rotation is allowed                         | Reflection is the main concept              |
| Mirror image is usually **not** accepted    | Left and right are reversed                 |
| Focus on tracing lines                      | Focus on horizontal reversal                |

If you master the rotation rule and learn to ignore distracting extra lines, Embedded Image questions become some of the quickest marks you can score in non-verbal reasoning.
