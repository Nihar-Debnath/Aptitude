Excellent! **Analogy** is one of the **most frequently asked reasoning topics** in placement exams like **TCS, Cognizant, Infosys, Capgemini, Wipro, and Accenture**.

It is also one of the easiest topics once you learn how to identify the relationship.

---

# What is Analogy?

An **Analogy** means:

> **A relationship between two things that is similar to the relationship between another two things.**

It is written as

```text
A : B :: C : ?
```

Read it as

> **"A is related to B in the same way that C is related to ?"**

Your job is to identify the relationship between **A and B** and apply the **same relationship** to **C**.

---

# Basic Example

```text
Dog : Puppy :: Cat : ?
```

Relationship

```text
Animal : Young One
```

Dog → Puppy

Cat → Kitten

Answer

```text
Kitten
```

---

# How to Solve Analogy Questions

Always follow these three steps.

### Step 1

Find the relationship between the first pair.

```text
A → B
```

### Step 2

Write that relationship in words.

### Step 3

Apply the same relationship to the second pair.

```text
C → ?
```

# Common Tricks Used in Exams

### Trick 1

Multiple relationships may seem possible.

Example

```text
Doctor : Hospital
```

Could mean

* Profession → Workplace ✅
* Person → Building ❌

Choose the **most specific** relationship.

---

### Trick 2

Direction matters.

Example

```text
Car : Wheel
```

means

Whole → Part

But

```text
Wheel : Car
```

means

Part → Whole

Don't reverse the relationship.

---

### Trick 3

Number Analogy

Example

```text
2 : 6
```

Could be

```text
×3
```

or

```text
+4
```

Always verify with the second pair.

# Common Mistakes

❌ Choosing an option from the same category instead of the same relationship.

Example:

```text
Doctor : Hospital :: Teacher : ?
```

Wrong:

```text
Student
```

Correct:

```text
School
```

The relationship is **Profession → Workplace**, not **Profession → Related Person**.

---

❌ Ignoring the direction of the analogy.

---

❌ Looking only at the words instead of the relationship.

# Analogy vs Classification

These two topics are often confused.

| Analogy                                     | Classification                              |
| ------------------------------------------- | ------------------------------------------- |
| Find the relationship between **two pairs** | Find the odd one out or group similar items |
| Format: `A : B :: C : ?`                    | Format: list of words, numbers, or figures  |
| Tests relationship matching                 | Tests grouping and categorization           |

### Final Strategy

Before looking at the second pair, always ask yourself:

> **"What exactly is the relationship between A and B?"**

Write it mentally in one short phrase, such as:

* Part → Whole
* Tool → Function
* Animal → Home
* Number → Square
* Letter → +2

Only then apply that same relationship to the second pair. This simple habit dramatically improves both speed and accuracy in analogy questions.
