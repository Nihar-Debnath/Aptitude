Excellent! The next topic is **Rule Detection** (also called **Rule Identification** or **Rule Inference**).

This topic is common in **TCS NQT, Cognizant GenC, Infosys, Wipro, Capgemini, Accenture**, and many logical reasoning tests.

Unlike Number Series or Figure Matrix, **Rule Detection is not about finding the next item.** It is about discovering **the hidden rule that governs a set of examples.**

---

# What is Rule Detection?

Rule Detection means:

> **Find the hidden rule or principle followed by the given examples and identify which option follows the same rule.**

Instead of asking,

> "What comes next?"

the question asks,

> "Which option follows the same rule?"

---

# Basic Example

Suppose you are given:

```text
ABC
DEF
GHI
```

And the rule is:

```text
Letters are arranged in alphabetical order.
```

Now consider the options:

```text
A) MNO
B) PRT
C) XZY
D) BDA
```

Which follows the same rule?

Answer:

```text
MNO
```

because the letters are also consecutive.

---

# Another Example

Given:

Hidden Rule

Options

```text
B) 3,5,7

C) 5,10,15

D) 1,2,3
```

Answer

```text
8,10,12
```

because it follows exactly the same rule.

# Step-by-Step Method

Whenever you solve a Rule Detection question:

### Step 1

Observe the examples carefully.

Don't look at the options first.

---

### Step 2

Ask

"What is changing?"

Possible changes

* Size
* Shape
* Direction
* Number
* Shading
* Rotation

---

### Step 3

Write the rule mentally.

Example

```text
Rotate 90°
```

or

```text
Add one dot
```

---

### Step 4

Apply that exact rule to the options.

---

### Step 5

Choose the option that follows **all** parts of the rule.

# Quick Solving Checklist

Whenever you see a Rule Detection question, check these properties in order:

1. ✅ Number pattern (addition, multiplication, squares, cubes)
2. ✅ Alphabet pattern (+1, +2, reverse, skips)
3. ✅ Shape transformation
4. ✅ Rotation (90°, 180°, 270°)
5. ✅ Mirror image
6. ✅ Shading (none, half, full)
7. ✅ Direction (arrows, triangles)
8. ✅ Size (small → large)
9. ✅ Position (left, right, up, down)
10. ✅ Count (dots, lines, corners, sides)

---

# Rule Detection vs Analogy vs Figure Matrix

These three topics are often confused.

| Topic              | What You Need to Do                                                      |
| ------------------ | ------------------------------------------------------------------------ |
| **Rule Detection** | Identify the hidden rule and find the option that follows it.            |
| **Analogy**        | Find the relationship between one pair and apply it to another pair.     |
| **Figure Matrix**  | Find the missing figure by discovering patterns across rows and columns. |

---

# Rule Detection in TCS & Cognizant

In placement exams, Rule Detection questions usually fall into one of these categories:

* **Number Rules** (even/odd, prime, square, cube, arithmetic patterns)
* **Alphabet Rules** (letter shifts, alphabetical order)
* **Figure Rules** (rotation, shading, addition/removal of elements)
* **Logical Rules** (object-function, animal-home, profession-workplace)

---

# Final Strategy

The best way to solve Rule Detection questions is to follow this order every time:

1. **Observe** the given examples only.
2. **Identify one change at a time**:

   * Rotation?
   * Shading?
   * Number?
   * Position?
   * Shape?
3. **State the rule in one short sentence.**

   * "Rotate 90° clockwise."
   * "Add one dot."
   * "Square becomes shaded."
4. **Test the rule against every example.**
5. **Only then check the options.**

This systematic approach is much more reliable than guessing and is exactly how these questions are designed to be solved in placement exams.
