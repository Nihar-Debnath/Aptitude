# How to prepare

Don't jump from topic to topic randomly.

Follow this cycle:

```
Concept
      ↓
Examples
      ↓
Easy Questions
      ↓
Medium Questions
      ↓
Timed Questions
      ↓
Previous Year Questions
      ↓
Revision after 3 days
      ↓
Mock Test
```

If you skip the timed practice, you'll know the concepts but still struggle in actual tests.

---

# For every topic

I recommend this sequence:

1. Learn the concept.
2. Write formulas in your own words.
3. Solve 10 easy questions.
4. Solve 15 medium questions.
5. Solve 10 difficult questions.
6. Solve previous company questions.
7. Note every mistake.
8. Revise after a few days.

# Make four important files

### Formula.md

Contains only formulas.

Example:

```

25% = 1/4

Percentage Increase

(New - Old) / Old ×100

Percentage Decrease

(Old - New) / Old ×100
```

### Mistakes.md

This file becomes gold after a month.

Example

```

❌ Used new value in denominator

❌ Didn't simplify fraction

❌ Rounded too early
```

Most people repeat the same mistakes because they never write them down.

### PYQs.md

Store every previous-year question that teaches something new.

# Time management during exams

A good rule is the **3-round approach**:

### Round 1 (Easy)

* Solve questions you know immediately.
* Skip anything taking more than about a minute.

### Round 2 (Medium)

* Return to questions that need some calculation.

### Round 3 (Hard)

* Attempt only if time remains.

Never get stuck on a single question early in the exam.

---

# What to practice besides questions

Practice these habits as well:

* Mental calculations (addition, subtraction, multiplication, division)
* Percentage-to-fraction conversions
* Squares (1–50)
* Cubes (1–20)
* Square roots of common perfect squares
* Cube roots of common perfect cubes
* Tables (1–30)
* Fraction-to-percentage conversions
* Percentage equivalents (e.g., 12.5% = 1/8, 16.67% ≈ 1/6)
* Approximation techniques
* Unit digit patterns
* Divisibility rules
* HCF and LCM shortcuts

These speed skills save valuable time in competitive exams.
