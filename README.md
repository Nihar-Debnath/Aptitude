# Daily Study Plan

**Total Time:** 3 hours

## Learning (2 hours)
- Learn as many topics as possible within the first 2 hours.

## Problem Solving (1 hour)
- Spend the remaining 1 hour minutes solving problems.
- Divide the time equally among all the topics you studied.

**Example:**
- If you learn **3 topics**, spend **20 minutes** solving problems for each topic.
