# Daily Study Plan

**Total Time:** 3 hours

## Learning (1 hour 45 minutes)
- Learn as many topics as possible within the first 1 hour 45 minutes.

## Problem Solving (1 hour 15 minutes)
- Spend the remaining 1 hour 15 minutes minutes solving problems.
- Divide the time equally among all the topics you studied.

**Example:**
- If you learn **3 topics**, spend **25 minutes** solving problems for each topic.
