# What is a Number System?

A **number system** is simply a way of representing and classifying numbers.

Examples:

* 5
* -12
* 3.14
* 1/2
* √2

All of these belong to different categories of numbers.

# Complete Syllabus of Number System

There are around **15 major topics**.

## 1. Types of Numbers ⭐⭐⭐⭐⭐

This is the foundation.

### Natural Numbers (N)

Counting numbers.

```
1 2 3 4 5...
```

No zero.

---

### Whole Numbers (W)

Natural numbers + Zero

```
0 1 2 3 4...
```

---

### Integers (Z)

Positive + Negative + Zero

```
... -3 -2 -1 0 1 2 3 ...
```

---

### Rational Numbers (Q)

Can be written as

```
p/q
```

where q ≠ 0.

Examples

```
1/2

3

-7

0.25

0.3333...
```

---

### Irrational Numbers

Cannot be written as p/q.

Examples

```
√2

√5

π

e
```

Their decimals never end and never repeat.

---

### Real Numbers

Everything except imaginary numbers.

```
Natural

Whole

Integers

Rational

Irrational
```

All together are Real Numbers.

# 2. Even and Odd Numbers ⭐⭐⭐⭐

Even

```
2
4
6
8
```

Divisible by 2.

Odd

```
1
3
5
7
```

Not divisible by 2.

Important properties:

Even + Even = Even

Odd + Odd = Even

Even + Odd = Odd

Even × Even = Even

Odd × Odd = Odd

Even × Odd = Even

Questions are frequently based on these rules.

---

# 3. Prime Numbers ⭐⭐⭐⭐⭐

A number having exactly two factors.

```
2

3

5

7

11

13
```

Important facts:

* 2 is the only even prime.
* 1 is NOT prime.
* Every prime except 2 is odd.

Must memorize primes till at least **100**.

# 8. HCF (Highest Common Factor)

Largest common factor.

Example

```

```

```

```

18

# 14. Cyclicity of Powers

Example

```
2^1 =2

2^2 =4

2^3 =8

2^4 =16

2^5 =32
```

Notice the unit digits:

```
2

4

8

6

2

4...

```

Cycle length = 4.

This helps solve unit-digit questions quickly.

# 15. Modular Arithmetic (Basics)

Used in remainder questions.

Example

```
15 mod 4 = 3
```

because

```
15 = 4×3 + 3
```
