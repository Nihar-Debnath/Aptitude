Yes! This is a **Number System → Unit Digit** question. 🔥

And this is actually a very easy topic once you understand the trick.

The question asks:

> What is the unit digit of
> [
> 213\times212\times347\times468\times778
> ]

---

# 1. What is a unit digit?

The **unit digit** means the **last digit** of a number.

For example:

* 237 → unit digit = **7**
* 5428 → unit digit = **8**
* 90123 → unit digit = **3**

So this question only wants the **last digit of the final answer**.

---

# 2. The BIG shortcut

When multiplying numbers, if you only need the unit digit:

> **Ignore every digit except the last digit.**

Look at our question:

[
213\times212\times347\times468\times778
]

Take only the last digit of each:

[
\boxed{3\times2\times7\times8\times8}
]

That's all!

You don't need to multiply those huge numbers.

---

# 3. Now calculate step by step

Start:

[
3\times2=6
]

Then:

[
6\times7=42
]

We only care about the **unit digit**:

[
\boxed{2}
]

Continue:

[
2\times8=16
]

Unit digit:

[
\boxed{6}
]

Then:

[
6\times8=48
]

Unit digit:

[
\boxed{8}
]

Therefore:

[
\boxed{8}
]

### ✅ Answer: **D) 8**

---

# 4. Why can we ignore the other digits?

This is the important concept.

Suppose:

[
213\times212
]

Break them:

[
213=210+3
]

[
212=210+2
]

When you multiply:

[
(210+3)(210+2)
]

Everything involving 210 will end in **0**.

The only part that determines the final unit digit is:

[
3\times2=6
]

So:

[
213\times212
]

must end in:

[
\boxed{6}
]

That's why we only need the last digits.

---

# 5. Another example

Suppose:

[
1234\times5678
]

Unit digits:

[
4\times8=32
]

Therefore unit digit:

[
\boxed{2}
]

No need to calculate (1234\times5678).

---

# 6. What if there are many numbers?

Example:

[
123\times456\times789\times234\times567
]

Take last digits:

[
3\times6\times9\times4\times7
]

Now work step by step, keeping only the last digit:

[
3\times6=18\rightarrow8
]

[
8\times9=72\rightarrow2
]

[
2\times4=8
]

[
8\times7=56\rightarrow6
]

Answer:

[
\boxed{6}
]

---

# 7. ⚠️ But powers are where Unit Digit becomes REALLY important

You'll also get questions like:

> Find the unit digit of (7^{123}).

You obviously can't calculate:

[
7\times7\times7\times\cdots
]

123 times.

Here we use **unit digit cycles**.

For 7:

[
7^1=7
]

[
7^2=49\rightarrow9
]

[
7^3=343\rightarrow3
]

[
7^4=2401\rightarrow1
]

Then the pattern repeats:

[
\boxed{7,9,3,1}
]

Cycle length = 4.

So for (7^{123}):

Divide exponent by 4:

[
123\div4
]

remainder:

[
3
]

So take the **3rd number in the cycle**:

[
\boxed{3}
]

---

# 🧠 So there are actually TWO major Unit Digit patterns

### Type 1 — Multiplication

Example:

[
213\times212\times347
]

Just take:

[
3\times2\times7
]

---

### Type 2 — Powers

Example:

[
7^{123}
]

Find the **unit-digit cycle** and use the remainder of the exponent.

---

Since you're preparing Numerical Ability, I'd learn Unit Digit in this order:

**1. Unit digit of multiplication** ← you just learned this

↓

**2. Unit digit of powers**

↓

**3. Cyclicity of 2, 3, 4, 7, 8, 9**

↓

**4. Unit digit of huge expressions**

For example:

[
3^{123}\times7^{456}\times9^{789}
]

↓

**5. Last two digits** (if your exam includes it)
