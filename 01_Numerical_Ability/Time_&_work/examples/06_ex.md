Yep! This one is **much easier** than the previous question. 😄

We have:

> **2 men can complete a work in 14 days.**
> How many men are required to complete the same work in **4 days**?

### 🧠 The key idea

For the **same amount of work**:

[
\boxed{\text{Men} \times \text{Days} = \text{Constant}}
]

Why?

If you increase the number of men, the work finishes faster.

So:

[
2 \times 14 = x \times 4
]

Calculate:

[
28=4x
]

[
x=7
]

### 🎯 Answer:

[
\boxed{7\text{ men}}
]

---

### 🔥 The shortcut you should remember

For these questions:

[
\boxed{M_1D_1=M_2D_2}
]

Here:

[
2\times14=x\times4
]

So:

[
\boxed{x=7}
]

### Why does this work?

Think:

**2 men → 14 days**

If you want the same work done in only **4 days**, you need more people.

Total "man-days":

[
2\times14=\boxed{28\text{ man-days}}
]

Now divide those 28 man-days among 4 days:

[
28\div4=\boxed7
]

So you need **7 men**.

This is one of the most important **Time & Work shortcuts** for aptitude exams.
