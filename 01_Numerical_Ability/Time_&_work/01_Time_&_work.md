# 1. The Basic Idea

Imagine one full work.

It may be

* Building a wall
* Painting a house
* Filling a tank
* Completing an assignment
* Digging a pit

No matter what...

**The entire work = 1**

or

**100%**

Example

If Ram builds a wall in 10 days,

then

```
Total work = 1
Time = 10 days
```

---

# First Formula

## Work = Rate × Time

Exactly like

```
Distance = Speed × Time
```

Here

```
Work = Efficiency × Time
```

or

```
Work = Rate × Time
```

---

# Therefore

## Rate

[
\boxed{\text{Rate}=\frac{\text{Work}}{\text{Time}}}
]

Since work is 1,

[
Rate=\frac1{Time}
]

This is the most important formula in the chapter.

---

# Example

A finishes work in 5 days.

Rate

[
=\frac15
]

Meaning

A completes

```
1/5 work every day
```

---

Another example

B takes

20 days.

Rate

[
=\frac1{20}
]

Meaning

Every day

B finishes

5%

of the work.

# 3. LCM Method (Fastest Method)

This is the trick almost every topper uses.

Instead of taking work = 1,

take work = LCM of the days.

---

Example

A

10 days

B

15 days

LCM

30

Assume

```
Total work =30 units
```

Now

A does

```
30/10=3 units/day
```

B does

```
30/15=2 units/day
```

Together

```
5 units/day
```

Time

[
30/5
]

[
6\text{ days}
]

Notice:

No fractions!

This method is much faster in exams.

# 13. Important Shortcuts

### Shortcut 1

Rate

=

1/Time

---

### Shortcut 2

Together

Add rates.

Never add time.

---

### Shortcut 3

Efficiency

Inverse of time.

---

### Shortcut 4

Worker × Days = Constant (when efficiency is the same)

[
\boxed{\text{Workers} \times \text{Days} = \text{Constant}}
]

Example:

20 workers finish a job in 15 days.

How many workers are needed to finish it in 10 days?

[
20 \times 15 = x \times 10
]

[
x = 30
]

---

### Shortcut 5

LCM Method

Use whenever possible to avoid fractions.

# Common Mistakes

❌ Adding days directly instead of rates.

❌ Forgetting that efficiency and time are inversely proportional.

❌ Mixing up completed work with remaining work.

❌ Using different units for men, women, and children without converting them.

❌ Forgetting to treat an outlet pipe as **negative work**.
