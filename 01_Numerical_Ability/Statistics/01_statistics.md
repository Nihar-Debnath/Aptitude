In numerical ability (aptitude) tests, **Statistics / Elementary Statistics** is the topic that deals with collecting, organizing, and interpreting numerical data. It's a common section in exams like TCS Ignite, bank POs, SSC, etc. Here's the core breakdown:

## Key Concepts Usually Tested

**1. Measures of Central Tendency**
- **Mean (Average)** = Sum of observations ÷ Number of observations
- **Median** = Middle value when data is arranged in order
- **Mode** = Most frequently occurring value

**2. Measures of Dispersion**
- **Range** = Maximum value − Minimum value
- **Mean Deviation**
- **Standard Deviation (SD)** = √(Σ(x − mean)² / n)
- **Variance** = (Standard Deviation)²

**3. Data Representation**
- Bar graphs, pie charts, line graphs, histograms
- Frequency distribution tables

**4. Common Question Types**
- Finding average of a data set
- "Average changes when a new element is added/removed" — e.g., average of 5 numbers is 20; a 6th number is added and average becomes 22, find the new number
- Weighted averages
- Combining averages of two groups (e.g., average marks of boys and girls combined)
- Reading and interpreting pie charts / bar graphs / tables and answering questions based on them

## Important Formulas to Remember

| Concept | Formula |
|---|---|
| Mean | Sum / Count |
| Average of first n natural numbers | (n+1)/2 |
| Average speed (equal distances) | 2xy / (x+y) |
| Combined average | (n₁×avg₁ + n₂×avg₂) / (n₁+n₂) |

## Why It Matters for TCS Ignite
This topic usually shows up as **data interpretation (DI)** sets — a chart or table followed by 3–5 questions — plus a few **standalone average/mean/median** questions. It's generally scoring if you're comfortable with basic averages and can read graphs quickly.
