# Q9

Replace the highest value (65) in the data

14, 18, 26, 32, 35, 38, 52, 65

so that **Mean = Median**.

Options:

A. 67  
B. 40  
C. 50  
D. 53

---

# Method 1 (Fast Logical Elimination) ⭐⭐⭐⭐⭐

Since only the **last element (65)** is replaced,

the new value must still be **greater than the second last element (52)**.

Otherwise, the order of the data changes.

So,

❌ 40 is eliminated.

❌ 50 is eliminated.

Remaining options:

- 67
- 53

Now think logically.

Current Median

= (32 + 35) / 2

= **33.5**

Replacing **65 with 67** increases the total sum by 2.

So the **Mean increases**, while the **Median remains 33.5**.

Therefore,

Mean > Median

So 67 cannot be the answer.

The only remaining option is

✅ **53**

---

# Method 2 (Using Variable x)

Replace 65 with x.

Current Sum

= 280

New Sum

= 280 - 65 + x

= 215 + x

Median

= (32 + 35) / 2

= 33.5

Since

Mean = Median

(215 + x) / 8 = 33.5

215 + x = 268

x = 53

✅ Answer = 53

---

# Method 3 (Using Effect on Mean)

Current Mean

= 280 / 8

= 35

Median

= 33.5

So,

Mean is **1.5 greater** than the Median.

To make them equal,

the Mean must decrease by **1.5**.

Since there are 8 observations,

the total sum must decrease by

1.5 × 8 = 12

But we are changing only the last element.

So,

New Value

= 65 - 12

= 53

✅ Answer = 53
