## Question

**Identify the statement which is NOT true.**

### a) It is compulsory to have mean, mode and median for a given data set.

❌ **False**

* Every data set has a **Mean**.
* Every data set has a **Median**.
* But a data set **may not have a Mode**.

Example:

1, 2, 3, 4, 5

Every number appears only once.

* Mean = 3 ✅
* Median = 3 ✅
* Mode = **No mode** ❌

So it is **not compulsory** to have a mode.

---

### b) We cannot have more than one mean, one median and one mode for a given data set.

❌ **False**

* Mean is always unique. ✅
* Median is generally unique (for aptitude purposes). ✅
* But **Mode can have more than one value.**

Example:

1, 1, 2, 2, 3

Frequencies:

* 1 → 2 times
* 2 → 2 times
* 3 → 1 time

Modes = **1 and 2**

This is called a **bimodal** data set.

So this statement is false because **a data set can have multiple modes.**

---

### c) Mean, Mode and Median has to be a value from given data set.

❌ **False**

This is only partly true.

Example:

1, 2, 3, 4

* Mean = (1+2+3+4)/4 = **2.5**
* Median = (2+3)/2 = **2.5**
* Mode = No mode

Notice that **2.5 is not present in the data set.**

Therefore, **Mean and Median do not have to be values from the given data set.**

Only the Mode (if it exists) must be one of the observed values.

---

### d) All the above are not true.

Let's verify:

* a → False ✅
* b → False ✅
* c → False ✅

Since **all three statements are false**, this statement is **true**.

---

# ✅ Correct Answer: **d) All the above are not true.**

---

## Shortcut to Remember

| Statement                   | True or False | Reason                                           |
| --------------------------- | ------------- | ------------------------------------------------ |
| Mean always exists          | ✅ True        | Can always be calculated                         |
| Median always exists        | ✅ True        | Can always be found                              |
| Mode always exists          | ❌ False       | Some data sets have no mode                      |
| More than one mode possible | ✅ True        | Bimodal/Multimodal data                          |
| Mean must be in data        | ❌ False       | Can be a decimal or new value                    |
| Median must be in data      | ❌ False       | Even number of observations can give a new value |
| Mode must be in data        | ✅ True        | It is the most frequent observed value           |

### Placement Exam Tip (TCS/CTS)

Memorize these three facts:

1. **Mean** → Can be outside the data values (e.g., 2.5).
2. **Median** → May or may not be a data value.
3. **Mode** → Must be a data value, but there can be **0, 1, or many** modes.

These concepts are frequently tested in aptitude exams.
