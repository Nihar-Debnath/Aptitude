

Yes. This is a **Time, Speed and Distance** problem, but the actual concept being tested here is mainly **ratio of speeds**.

Let's solve it from absolute zero.

## 1. First understand what the question is saying

> The ratio between the speeds of two trains is **7 : 8**.

Let's call:

* First train's speed = **7 parts**
* Second train's speed = **8 parts**

So:

```text
First : Second
  7   :   8
```

Then it says:

> The second train runs **400 km in 4 hours**.

So we can find the **actual speed of the second train**.

---

# 2. Remember the basic formula


The fundamental relationship is:

**Speed = Distance ÷ Time**

So for the second train:

\[
\text{Speed} = \frac{400}{4}=100\text{ km/h}
\]

Therefore:

> **Second train's speed = 100 km/h**

---

# 3. Now use the ratio

We know:

```text
First : Second
  7   :   8
```

And we discovered:

```text
Second = 100 km/h
```

So:

```text
8 parts = 100 km/h
```

Therefore:

```text
1 part = 100/8 = 12.5 km/h
```

First train has **7 parts**:

\[
7\times12.5=87.5
\]

Therefore:

# **Answer = 87.5 km/h**

---

# 4. There's an even faster way

You don't always need to calculate 1 part.

The ratio is:

\[
\frac{\text{First speed}}{\text{Second speed}}=\frac{7}{8}
\]

Second speed = 100 km/h.

Therefore:

\[
\text{First speed}
\=100\times\frac{7}{8}
]

\[
=87.5\text{ km/h}
\]

Done.

---

# 5. But what is this "train problem"?

Don't get scared by the word **train**.

This question doesn't actually involve any special train concept.

It is simply:

### **Ratio + Speed = Distance/Time**

You don't need:

* length of trains
* crossing trains
* platforms
* relative speed
* opposite directions

None of that is involved here.

The train is just the **object whose speed we're discussing**.

---

# 6. What you should learn from this question

This is a very common **Time, Speed & Distance (TSD)** question.

You need to understand these basic relationships:

```text
             Distance
          ───────────────
          Speed × Time
```

Meaning:

\[
S=\frac{D}{T}
\]

\[
D=S\times T
\]

\[
T=\frac{D}{S}
\]

And when **two speeds are given in a ratio**, you combine the ratio with the actual speed.

---

# 7. Let's see the logic visually

Suppose:

```text
First train       Second train
    ↓                  ↓
   7 parts           8 parts
```

Second train:

```text
8 parts = 100 km/h
```

Therefore:

```text
1 part = 12.5 km/h
```

So:

```text
First = 7 × 12.5
      = 87.5 km/h
```

That's the entire question.

---

# 8. One thing you should NOT do

You might initially think:

> Ratio is 7:8, so answer must be 7/8 or 8/7.

No.

**7:8 is only telling you the relationship between the two speeds.**

You need one actual speed to determine the actual speeds.

Here we got:

> Second speed = 400/4 = 100 km/h

Then we used the ratio.

---

# 9. A general shortcut you can memorize

If:

\[
A:B=m:n
\]

and you know:

\[
B=x
\]

then:

\[
A=x\times\frac{m}{n}
\]

For this question:

\[
A:B=7:8
\]

\[
B=100
\]

Therefore:

\[
A=100\times\frac78=87.5
\]
