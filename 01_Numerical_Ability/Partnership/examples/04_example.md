Yep! This one is actually **much easier** than the previous question because **there is no time involved**.

Let's go step by step.

## Given

Total investment of A, B and C together:

\[
₹50,000
\]

A invests **₹4,000 more than B**.

B invests **₹5,000 more than C**.

Total profit:

\[
₹35,000
\]

Find **A's profit**.

---

# Step 1: Find everyone's investment

We know:

> A is ₹4,000 more than B.

And:

> B is ₹5,000 more than C.

Let's start with **C**.

Suppose C invests:

\[
x
\]

Then B invests:

\[
x+5000
\]

And A invests ₹4,000 more than B:

\[
(x+5000)+4000
\]

So:

\[
A=x+9000
\]

Therefore:

| Person | Investment |
| ------ | ---------: |
| C      |        (x) |
| B      |  (x+5,000) |
| A      |  (x+9,000) |

---

# Step 2: Total investment is ₹50,000

So:

\[
x+(x+5000)+(x+9000)=50000
\]

Combine:

\[
3x+14000=50000
\]

Subtract 14,000:

\[
3x=36000
\]

\[
x=12000
\]

So C invested:

\[
\boxed{₹12,000}
\]

---

# Step 3: Find B and A

### C

₹12,000

### B

B is ₹5,000 more:

\[
12000+5000=\boxed{₹17,000}
\]

### A

A is ₹4,000 more than B:

\[
17000+4000=\boxed{₹21,000}
\]

So:

\[
\boxed{A:B:C=21000:17000:12000}
\]

---

# Step 4: Convert investment into profit ratio

There is **no time difference mentioned**, so this is the simple case.

Therefore:

\[
\text{Profit ratio}=\text{Investment ratio}
\]

So:

\[
A:B:C=21000:17000:12000
\]

---

# Step 5: Find A's profit

Total investment:

\[
21000+17000+12000=50000
\]

A's fraction:

\[
\frac{21000}{50000}
\]

Total profit:

\[
₹35000
\]

Therefore:

\[
A's\ profit=
\frac{21000}{50000}\times35000
\]

Cancel:

\[
=\frac{21}{50}\times35000
\]

\[
=21\times700
\]

\[
=\boxed{₹14,700}
\]

# ✅ Final Answer

\[
\boxed{\text{A receives ₹14,700}}
\]

So the correct option is **D. ₹14,700** ✅

---

## 🧠 What is NEW in this question?

This question is testing a different skill.

Previously, we had:

> **Investment × Time**

Here, **time isn't given**, so we don't need it.

Instead, first find the **actual investments** using the statements:

> A = B + 4,000
> B = C + 5,000
> A + B + C = 50,000

Then once you know the investments, simply use:

\[
\boxed{\text{Profit Ratio}=\text{Investment Ratio}}
\]

So the flow is:

**Find investments → make ratio → divide profit.**
