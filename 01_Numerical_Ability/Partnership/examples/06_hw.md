Yep — this is a **Partnership** question. The key formula is:

[
\boxed{\text{Profit} \propto \text{Investment}\times\text{Time}}
]

So,

[
\boxed{\text{Investment ratio}
=

\frac{\text{Profit ratio}}{\text{Time ratio}}}
]

### Given

Time periods:

[
P:Q:R=3:4:5
]

Profits:

[
P:Q:R=5:6:8
]

Therefore:

[
\text{Investment ratio}
=

\frac{5}{3}:\frac{6}{4}:\frac{8}{5}
]

Now simplify:

[
=\frac53:\frac32:\frac85
]

We need to remove the fractions. **LCM of 3, 2, 5 = 30**

Multiply everything by 30:

[
\frac53\times30=50
]

[
\frac32\times30=45
]

[
\frac85\times30=48
]

Therefore:

[
\boxed{P:Q:R=50:45:48}
]

### ✅ Answer

[
\boxed{\boxed{50:45:48}}
]

### 🧠 Remember this for aptitude

For partnership:

[
\boxed{P \propto I\times T}
]

So:

[
\boxed{I=\frac{P}{T}}
]

**Profit ratio ÷ Time ratio = Investment ratio.**
