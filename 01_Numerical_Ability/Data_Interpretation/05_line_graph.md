Great! **Line Graph DI** is actually one of the easiest DI topics once you understand one thing:

> **A line graph shows how a value changes over time (or another ordered sequence).**

Unlike:

* **Table DI** → data is in rows and columns.
* **Bar Graph** → compares different categories.
* **Pie Chart** → shows parts of a whole.
* **Line Graph** → shows **trend** (increase, decrease, fluctuations).

---

## Example

Imagine a company's profit over six months.

![](./Monthly%20company%20profit.png)

Each point represents the profit for that month, and the line simply connects those points to show the trend.

# How to read a line graph

There are two axes:

### X-axis (Horizontal)

Usually represents:

* Months
* Years
* Days
* Time

### Y-axis (Vertical)

Represents the value:

* Profit
* Sales
* Temperature
* Population
* Number of students

---

# Types of questions

## 1. Highest value

**Question:** In which month was the profit highest?

Look for the highest point.

**Answer:** June (40)

---

## 2. Lowest value

Look for the lowest point.

**Answer:** January (20)

---

## 3. Increase

**Question:** How much did profit increase from January to April?

[
35-20=15
]

---

## 4. Decrease

**Question:** By how much did profit decrease from April to May?

[
35-30=5
]

---

## 5. Percentage increase

From January to February

[
\frac{28-20}{20}\times100
=========================

40%
]

---

## 6. Average

Average profit

[
\frac{20+28+25+35+30+40}{6}
]

---

## 7. Difference between two years/months

Very common.

Example:

Sales in 2022 = 420

Sales in 2025 = 610

Difference

[
610-420=190
]

---

# Double Line Graph

Sometimes there are **two lines**.

Example:

* Blue → Company A
* Red → Company B

Questions become:

* Which company sold more in March?
* Difference between A and B in June?
* Which company had higher average sales?

This is one of the most common placement DI questions.

---

# Things students forget

### 1. Read the scale

Sometimes

```
20
40
60
80
100
```

Sometimes

```
200
400
600
800
1000
```

Sometimes each division is **5**, **10**, **20**, or **50**.

Always check the y-axis before solving.

---

### 2. Don't guess from the slope

A steeper line **does not automatically mean a larger increase** unless you look at the actual values.

Always read the numbers.

---

### 3. Read exact values

Sometimes a point is:

* 62
* 64
* 66

Don't assume it's 65.

---

# Shortcut tips

When you need:

### Highest

→ Highest point.

### Lowest

→ Lowest point.

### Difference

→ Bigger − Smaller.

### Increase %

→

[
\frac{\text{Increase}}{\text{Original}}\times100
]

### Decrease %

→

[
\frac{\text{Decrease}}{\text{Original}}\times100
]

# Comparison of all four DI types

| DI Type    | What it shows      | Main skill               |
| ---------- | ------------------ | ------------------------ |
| Table      | Exact numbers      | Reading values           |
| Pie Chart  | Part of a whole    | Percentage, ratio        |
| Bar Graph  | Compare categories | Difference, average      |
| Line Graph | Change over time   | Trend, increase/decrease |

---

# Placement exam tip

For companies like **TCS, Cognizant, Wipro, Accenture, and Capgemini**, line graph questions almost always revolve around:

* Highest/lowest value
* Increase or decrease
* Percentage increase/decrease
* Average
* Difference between two time periods

The graph itself is easy to read. The real challenge is doing the calculations quickly.
