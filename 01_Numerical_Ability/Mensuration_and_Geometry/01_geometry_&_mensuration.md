# What is Geometry?

Geometry is the branch of mathematics that deals with:

- Shapes
- Angles
- Lines
- Properties of figures
- Relationships between figures

Geometry mainly asks questions like:

- Find the angle.
- Identify the shape.
- Find missing sides.
- Apply geometric properties.

### Example

**Question**

ABC is an equilateral triangle.

Find ∠B.

Since every angle in an equilateral triangle is **60°**,

**Answer = 60°**

Notice that no area or volume is involved.

---

# What is Mensuration?

Mensuration is the branch of mathematics that deals with measuring figures.

It focuses on:

- Area
- Perimeter
- Surface Area
- Volume

### Example

A rectangle has

Length = 10 cm

Breadth = 8 cm

Area = Length × Breadth

= 10 × 8

= **80 cm²**

## Right Angle

# Complementary Angles

Two angles whose sum is

```
90°
```

Example

```

```

# Supplementary Angles

Two angles whose sum is

```
180°
```

Example

```
110° + 70° = 180°

95° + 85° = 180°
```

# Angles on a Straight Line

Angles on a straight line always add up to

```
180°
```

Example

Angles around a point always add up to

```
360°

Example

```

# 2. Triangles

Triangles are the most important geometry topic for placement exams.

A triangle has

- Three sides
- Three angles

The sum of its interior angles is always

```
180°
```

---

# Types of Triangles

Triangles can be classified in two ways.

## Based on Sides

- Equilateral
- Isosceles
- Scalene

## Based on Angles

- Acute
- Right
- Obtuse

---

# Equilateral Triangle

Properties

- All three sides are equal.
- All three angles are equal.
- Every angle is

```
60°
```

Example

```
      /\
     /  \
    /____\
```

All sides equal

Every angle = 60°

---

# Isosceles Triangle

Properties

- Two sides are equal.
- Base angles are equal.

Example

```
    /\
   /  \
  /____\
```

If one base angle is

```
50°
```

The other base angle is also

```
50°
```

---

# Scalene Triangle

Properties

- No side is equal.
- No angle is equal.

Example

Every side has a different length.

---

# Acute Triangle

# Angle Sum Property

The three interior angles of every triangle always add up to

```
180°
```

Formula

```
A + B + C = 180°
```

### Example

```
50° + 60° + x = 180°

x = 70°
```

---

# Exterior Angle Property

An exterior angle of a triangle equals the sum of the two opposite interior angles.

Example

```
40°

60°
```

Exterior angle

```
100°
```

---

# Triangle Inequality Property

A triangle can only exist if

```
Sum of any two sides

>

Third side
```

Example

Sides

```
4

5

10
```

Cannot form a triangle because

```
4 + 5 = 9

9 < 10
```

---

# Area of Triangle

Formula

```
Area = (1/2) × Base × Height
```

Example

Base = 10 cm

Height = 8 cm

```
Area

= 1/2 × 10 × 8

= 40 cm²
```

---

# Pythagoras Theorem

Applicable only for right-angled triangles.

Formula

```
a² + b² = c²
```

Where

- a = Perpendicular
- b = Base
- c = Hypotenuse

Example

```
Base = 3

Height = 4

Hypotenuse = 5
```

Because

```
3² + 4²

= 9 + 16

= 25

√25

= 5
```

# Quick Revision

## Angle Facts

- Straight angle = **180°**
- Full angle = **360°**
- Right angle = **90°**
- Complementary angles = **90°**
- Supplementary angles = **180°**
- Angles on a straight line = **180°**
- Angles around a point = **360°**
- Alternate angles = Equal
- Corresponding angles = Equal
- Co-interior angles = **180°**

---

## Triangle Facts

- Sum of interior angles = **180°**
- Exterior angle = Sum of opposite interior angles
- Area = **½ × Base × Height**
- Right triangle uses **Pythagoras theorem**
- Equilateral triangle → All angles = **60°**
- Isosceles triangle → Base angles are equal
- Triangle inequality must always hold.
