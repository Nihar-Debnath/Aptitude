# 3. Quadrilaterals

A quadrilateral is a polygon having **4 sides**.

## Basic Property

The sum of all interior angles of every quadrilateral is

```
360°
```

Example

```
90° + 80° + 100° + 90° = 360°
```

---

# Types of Quadrilaterals

1. Square
2. Rectangle
3. Parallelogram
4. Rhombus
5. Trapezium (Trapezoid in some countries)
6. Kite

For placement exams, mainly focus on the first five.

---

# Square

A square is a special quadrilateral where all sides are equal.

## Properties

- All four sides are equal.
- All four angles are 90°.
- Opposite sides are parallel.
- Diagonals are equal.
- Diagonals bisect each other at 90°.

Example

```
+------+
|      |
|      |
|      |
+------+
```

---

## Formulas

### Area

```
Side²

Area = a²
```

### Perimeter

```
4 × Side

Perimeter = 4a
```

### Diagonal

```
a√2
```

---

## Example

Side = 8 cm

Area

```
8²

= 64 cm²
```

Perimeter

```
4 × 8

= 32 cm
```

Diagonal

```
8√2 cm
```

---

# Rectangle

A rectangle has opposite sides equal.

## Properties

- Opposite sides equal.
- All angles = 90°.
- Diagonals are equal.
- Opposite sides are parallel.

Example

```
+----------+
|          |
|          |
+----------+
```

---

## Formulas

### Area

```
Length × Breadth

Area = l × b
```

### Perimeter

```
2(l+b)
```

### Diagonal

Using Pythagoras

```
√(l²+b²)
```

---

## Example

Length = 12 cm

Breadth = 5 cm

Area

```
12 × 5

= 60 cm²
```

Perimeter

```
2(12+5)

= 34 cm
```

Diagonal

```
√(12²+5²)

= √169

= 13 cm
```

---

# Parallelogram

A parallelogram has opposite sides parallel.

## Properties

- Opposite sides equal.
- Opposite angles equal.
- Adjacent angles are supplementary.
- Diagonals bisect each other.

Example

```
 ________
/       /
/_______/
```

---

## Formulas

Area

```
Base × Height
```

Perimeter

```
2(a+b)
```

---

## Example

Base = 9 cm

Height = 6 cm

Area

```
9 × 6

= 54 cm²
```

---

# Rhombus

A rhombus has all sides equal.

Looks like a tilted square.

## Properties

- All sides equal.
- Opposite angles equal.
- Diagonals bisect each other at 90°.

Example

```
   /\
  /  \
  \  /
   \/
```

---

## Formula

Area

```
½ × d₁ × d₂
```

where

```
d₁ = First diagonal

d₂ = Second diagonal
```

Perimeter

```
4a
```

---

## Example

Diagonals

```
12 cm

10 cm
```

Area

```
½ × 12 × 10

= 60 cm²
```

---

# Trapezium

A trapezium has

```
One pair of parallel sides.
```

Example

```
 ______
/      \
--------
```

---

## Formula

Area

```
½ × (a+b) × h
```

where

- a = First parallel side
- b = Second parallel side
- h = Height

---

## Example

Parallel sides

```
10

6
```

Height

```
4
```

Area

```
½ × (10+6) ×4

= 32 cm²
```

---

# Kite

## Properties

- Two pairs of adjacent sides are equal.
- One pair of opposite angles is equal.
- Diagonals intersect at 90°.

Formula

```
Area

= ½ × d₁ × d₂
```

---

# Summary Table

| Shape | Area | Perimeter |
|--------|------|-----------|
| Square | a² | 4a |
| Rectangle | l×b | 2(l+b) |
| Parallelogram | bh | 2(a+b) |
| Rhombus | ½d₁d₂ | 4a |
| Trapezium | ½(a+b)h | Sum of all sides |

---

# Interior Angle Sum

This is the most important polygon formula.

```
(n−2) ×180°
```

where

```
n

=

Number of sides
```

---

## Example 1

Pentagon

```
n=5
```

```
(5−2)×180

=540°
```

---

## Example 2

Hexagon

```
(6−2)×180

=720°
```

---

# Each Interior Angle of a Regular Polygon

Formula

```
[(n−2)×180]/n
```

---

## Example

Regular Pentagon

```
540/5

=108°
```

---

# Exterior Angles

The sum of exterior angles of **every polygon** is always

```
360°
```

Remember this.

It is frequently asked.

---

# Diagonals of a Polygon

Formula

```
n(n−3)/2
```

---

## Example

Hexagon

```
6(6−3)/2

=9 diagonals
```

# 5. Circle

Circle questions are extremely common in aptitude.

---

# Important Terms

## Centre

The middle point of a circle.

---

## Radius (r)

Distance from the centre to the boundary.

Example

```
Centre ------ Boundary
```

---

## Diameter (d)

A line passing through the centre.

Formula

```
Diameter

=2r
```

---

## Radius from Diameter

```
r=d/2
```

---

## Circumference

Distance around the circle.

Formula

```
2πr
```

or

```
πd
```

---

## Example

Radius

```
7 cm
```

Circumference

```
2 ×22/7×7

=44 cm
```

---

# Area of Circle

Formula

```
πr²
```

---

## Example

Radius

```
7 cm
```

Area

```
22/7 ×49

=154 cm²
```

---

# Chord

A chord is a line joining any two points on the circle.

Important Fact

```
Diameter

=

Longest chord
```

---

# Arc

A part of the circumference.

Example

```
Small curved portion
```

---

# Sector

A region enclosed by

- Two radii
- One arc

Looks like a pizza slice.

---

# Segment

The region enclosed by

- One chord
- One arc

---

# Tangent

A line touching the circle at exactly one point.

Important Property

```
Radius ⟂ Tangent
```

The radius is always perpendicular to the tangent.

---

# Secant

A line cutting the circle at two points.

---

# Value of π

```

or

```
3.14
