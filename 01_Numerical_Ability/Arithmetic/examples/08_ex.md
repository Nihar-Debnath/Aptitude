Yes 😄 This one looks scary because of (2^{32}), but **you absolutely do NOT calculate (2^{32})**.

The trick is to **factor (x)**.

We have:

[
x=2^{32}-1
]

### Step 1: Use (a^2-b^2)

[
2^{32}-1
]

can be written as:

[
(2^{16})^2-1^2
]

So:

[
x=(2^{16}-1)(2^{16}+1)
]

Now factor those further:

[
2^{16}-1=(2^8-1)(2^8+1)
]

[
=(2^4-1)(2^4+1)(2^8+1)
]

And:

[
2^4-1=15=3\times5
]

[
2^4+1=17
]

[
2^8+1=257
]

So:

[
x=3\times5\times17\times257\times65537
]

We don't care about the huge numbers because we're only looking for factors **below 100**.

---

## Step 2: Find all factors below 100

The small prime factors are:

[
3,\quad5,\quad17
]

Now we can multiply them:

### Individual factors

[
3,\quad5,\quad17
]

### Two-factor combinations

[
3\times5=15
]

[
3\times17=51
]

[
5\times17=85
]

### Three-factor combination

[
3\times5\times17=255
]

Too big ❌

So the factors **between 1 and 100** are:

[
\boxed{3,5,15,17,51,85}
]

Notice **1 isn't included** because "between 1 and 100" means greater than 1 and less than 100 here.

---

### Step 3: Add them

[
3+5+15+17+51+85
]

[
=176
]

Therefore:

[
\boxed{176}
]

### 🔥 The exam trick

For a question like:

[
2^{32}-1
]

Don't calculate the number.

Remember:

[
\boxed{a^{2}-b^{2}=(a-b)(a+b)}
]

So:

[
2^{32}-1=(2^{16}-1)(2^{16}+1)
]

Then keep breaking down the **minus** part until you get small factors:

[
2^{32}-1
\rightarrow
(2^{16}-1)(2^{16}+1)
\rightarrow
3\times5\times17\times257\times65537
]

Then only use the factors that can make numbers **< 100**.

That's the entire trick. 👍
