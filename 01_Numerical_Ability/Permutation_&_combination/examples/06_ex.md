> How many positive integers less than 600 can be formed using the numbers 1,3,4 and 6 for digits and each digit is used only once ? 


Of course 😄 Let's slow it **way down**. This question looks like P&C, but the trick is actually very simple.

> **How many positive integers less than 600 can be formed using 1, 3, 4, 6, with each digit used only once?**

Available digits:

**1, 3, 4, 6**

We can make numbers like:

`1, 3, 4, 6`
`13, 14, 16, 31, 34, 36...`
`134, 136, 146, 314...`

But **NOT 4-digit numbers**, because any 4-digit number is at least 1000.

So we only need to count:

**1-digit + 2-digit + 3-digit numbers**

---

# 🟢 Case 1: 1-digit numbers

Our digits are:

`1  3  4  6`

Each one is a valid positive integer less than 600.

So:

**4 numbers**

---

# 🟢 Case 2: 2-digit numbers

Let's actually understand this instead of jumping to `4P2`.

We need something like:

`_ _`

### First position

We can put any of the 4 digits:

**1, 3, 4, 6**

So:

**4 choices**

Suppose we choose `1`:

`1 _`

We cannot use 1 again.

Remaining:

`3, 4, 6`

So the second position has:

**3 choices**

Therefore:

**4 × 3 = 12**

So there are **12 two-digit numbers**.

For example:

`13, 14, 16`

`31, 34, 36`

`41, 43, 46`

`61, 63, 64`

That's 12.

---

# 🔴 Case 3: 3-digit numbers

Now we need:

`_ _ _`

But there's an important condition:

> **The number must be less than 600.**

This is where the question becomes interesting.

Look at the first digit.

If we put **6** first:

`6 _ _`

What is the smallest possible number?

`613` (for example)

That's already **greater than 600**.

So:

❌ `6 _ _` is NOT allowed.

Therefore, the first digit can only be:

**1, 3, or 4**

So:

### First digit → 3 choices

Let's say we choose `3`.

We now have:

`3 _ _`

Available digits are:

`1, 4, 6`

We can choose any of these for the second position.

So:

### Second digit → 3 choices

Suppose we choose `1`:

`31 _`

Remaining digits:

`4, 6`

So:

### Third digit → 2 choices

Therefore:

[
3\times3\times2 = 18
]

So there are **18 three-digit numbers**.

---

# 🟡 Now put everything together

We have:

| Number type | Number of possibilities |
| ----------- | ----------------------: |
| 1-digit     |                       4 |
| 2-digit     |                      12 |
| 3-digit     |                      18 |

Therefore:

[
4+12+18
]

[
=\boxed{34}
]

# 🎯 Final Answer: 34

---

## The BIG thing you need to understand

Don't think:

> "Why are we doing 4 × 3 × 2?"

Think about **positions**.

For example, making a 3-digit number:

```text
  Hundreds   Tens   Units
      ↓        ↓      ↓
      _        _      _
```

For a normal 3-digit number:

```text
4 choices × 3 choices × 2 choices
```

But because the number must be **< 600**, `6` cannot go in the hundreds position:

```text
Hundreds   Tens   Units
   ↓        ↓      ↓
  3 choices × 3 × 2
```

That's the entire trick.

### ⭐ Remember this for TCS:

Whenever you see:

> **"How many numbers less than ___ can be formed using these digits?"**

**First ask:**

> **How many digits can the number have?**

Then handle each digit-length separately.

And if there's a limit like **< 600**, **> 300**, etc., look carefully at the **first digit**.

Ahhh — **you absolutely can use (nP r)** for the 3-digit case. In fact, that's a very good way to solve it. 😄

The reason I wrote:

[
3\times3\times2
]

is because I was explaining the choices step-by-step. But this is exactly the same thing as a permutation.

### For the 3-digit numbers:

We have 4 digits:

[
{1,3,4,6}
]

But the **first digit cannot be 6**, because the number must be less than 600.

So for the **first position**, we have only:

[
3 \text{ choices } = {1,3,4}
]

Once we choose the first digit, we have **3 digits remaining**, and we need to arrange **2 of them** in the tens and units positions.

So:

[
{}^3P_2
]

Therefore:

[
3\times{}^3P_2
]

And:

[
{}^3P_2 = \frac{3!}{(3-2)!}
= \frac{3!}{1!}
=6
]

Therefore:

[
3\times6=\boxed{18}
]

### Why did we use (4P2) for the 2-digit case?

Because **any of the 4 digits** can be the first digit:

[
{}^4P_2=4\times3=12
]

For the 3-digit case, **6 is forbidden from the first position**, so we can't simply do:

[
{}^4P_3
]

Instead:

[
\boxed{3\times{}^3P_2}
]

### 🔥 Remember this pattern

If there is a restriction on the **first digit**, do:

> **Choices for first digit × permutation of remaining positions**

That's exactly what happened here.
