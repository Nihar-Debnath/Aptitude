Yep bro, this one is **much simpler**. Let's solve it step by step.

### Given

> Ram is **3 times** as old as Shyam.

So if Shyam's present age is (x):

[
\text{Shyam}=x
]

[
\text{Ram}=3x
]

---

### After 15 years

Both will become 15 years older:

```text
Now:          After 15 years:

Shyam = x     → x + 15
Ram   = 3x    → 3x + 15
```

The question says:

> Ram will be **twice** as old as Shyam.

Therefore:

[
3x+15=2(x+15)
]

Expand:

[
3x+15=2x+30
]

[
3x-2x=30-15
]

[
x=15
]

So Shyam is:

[
\boxed{15}
]

Ram is:

[
3\times15=\boxed{45}
]

### ✅ Answer

**Shyam = 15 years**

**Ram = 45 years**

---

### Quick check

Now:

```text
Ram   = 45
Shyam = 15

45 = 3 × 15 ✅
```

```text
Ram   = 60

```
