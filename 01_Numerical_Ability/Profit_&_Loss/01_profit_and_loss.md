# PROFIT & LOSS (Complete Notes)

---

# 1. Basic Terminology

Before solving anything, understand these four words.

## Cost Price (CP)

The price at which a shopkeeper **buys** an item.

Example

Bought a laptop for ₹40,000

CP = ₹40,000

---

## Selling Price (SP)

The price at which the shopkeeper **sells** the item.

Example

Sold it for ₹45,000

SP = ₹45,000

---

## Profit (Gain)

If

```
SP > CP
```

then seller earns profit.

Formula

[
\boxed{Profit = SP - CP}
]

Example

Bought for ₹500

Sold for ₹620

Profit

[
620-500=120
]

Profit = ₹120

---

## Loss

If

```
SP < CP
```

then seller incurs loss.

Formula

[
\boxed{Loss = CP - SP}
]

Example

Bought for ₹900

Sold for ₹750

Loss

[
900-750=150
]

Loss = ₹150

---

# 2. Three Cases

### Case 1

SP > CP

Profit

Example

CP = 100

SP = 120

Profit = 20

---

### Case 2

SP < CP

Loss

Example

CP = 100

SP = 80

Loss = 20

---

### Case 3

SP = CP

No Profit

No Loss

---

# 3. Profit Percentage

Profit is always calculated on **Cost Price**, not Selling Price.

Formula

[
\boxed{
Profit%=
\frac{Profit}{CP}\times100
}
]

or

[
\boxed{
Profit%=
\frac{SP-CP}{CP}\times100
}
]

---

Example

CP = 400

SP = 500

Profit

[
500-400=100
]

Profit %

[
\frac{100}{400}\times100
=25%
]

---

# 4. Loss Percentage

Formula

[
\boxed{
Loss%=
\frac{Loss}{CP}\times100
}
]

or

[
\boxed{
Loss%=
\frac{CP-SP}{CP}\times100
}
]

---

Example

CP = 800

SP = 680

Loss

[
120
]

Loss %

[
\frac{120}{800}\times100
=15%
]

# 5. Finding Selling Price

## From Profit %

Formula

[
\boxed{
SP=
CP\left(1+\frac{Profit%}{100}\right)
}
]

Example

CP = 800

Profit = 20%

[
SP
=800\times1.2
=960
]

---

## From Loss %

Formula

[
\boxed{
SP=
CP\left(1-\frac{Loss%}{100}\right)
}
]

Example

CP = 500

Loss = 10%

[
SP
=500\times0.9
=450
]

---

# 6. Finding Cost Price

When SP and profit are given

Formula

[
\boxed{
CP=
\frac{SP\times100}
{100+Profit%}
}
]

---

Example

SP = 960

Profit = 20%

[
CP
=\frac{960\times100}{120}
=800
]

---

When SP and loss are given

Formula

[
\boxed{
CP=
\frac{SP\times100}
{100-Loss%}
}
]

---

Example

SP = 720

Loss = 10%

[
CP
==

\frac{720\times100}{90}
=800
]

# 17. Common Mistakes

❌ Calculating profit percentage on SP instead of CP.

❌ Forgetting that profit and loss percentages are based on CP unless stated otherwise.

❌ Using the wrong formula for CP when SP and percentage are given.

❌ Confusing discount (based on Marked Price) with loss (based on Cost Price).

❌ Adding successive percentages directly (e.g., +20% then +10% is **not** +30%; multiply the factors instead).

# 19. High-Speed Exam Tips

* **Step 1:** Identify what is given: CP, SP, Profit %, or Loss %.
* **Step 2:** Check whether it's a **profit**, **loss**, or **no profit/no loss** case.
* **Step 3:** Use ratios (e.g., 20% profit → CP:SP = 5:6) whenever possible to avoid formulas.
* **Step 4:** Convert common percentages into fractions (25% = 1/4, 20% = 1/5, 33⅓% = 1/3, etc.) for faster mental calculations.
* **Step 5:** Avoid unnecessary arithmetic—many placement questions can be solved by comparing ratios and simplifying fractions.

# 20. Prerequisites for Profit & Loss

Profit & Loss builds on several earlier aptitude topics. Make sure you're comfortable with:

* **Percentages** (most important prerequisite)
* **Fractions and their percentage equivalents**
* **Ratio and Proportion**
* **Basic multiplication tables** (up to at least 20, ideally 30–50 for speed)
* **Squares of common numbers** (helps in quick calculations)
* **Mental arithmetic** (addition, subtraction, multiplication, and division)
