# 1. What is Simplification?

Simplification means **finding the value of an expression using mathematical rules**.

Example:

[
25+15\times4
]

Wrong:

[
(25+15)\times4=160
]

Correct:

[
25+(15\times4)
]

[
25+60=85
]

Because multiplication comes before addition.

---

# 2. BODMAS Rule (Most Important)

Every simplification question follows the same order.

| Letter | Meaning                |
| ------ | ---------------------- |
| B      | Brackets               |
| O      | Orders (Powers, Roots) |
| D      | Division               |
| M      | Multiplication         |
| A      | Addition               |
| S      | Subtraction            |

Remember:

* Division and multiplication have the **same priority**.
* Addition and subtraction also have the **same priority**.
* When priorities are equal, solve **from left to right**.

---

## Example 1

[
20-4+8
]

Solve left to right:

[
20-4=16
]

[
16+8=24
]

Wrong:

[
20-(4+8)=8
]

---

## Example 2

[
24\div6\times2
]

Left to right:

[
24\div6=4
]

[
4\times2=8
]

Wrong:

[
24\div12=2
]

# 3. Brackets

Solve brackets from **innermost to outermost**.

Order:

```text
( )
↓
{ }
↓
[ ]
```

Example:

[
20-{5+[8-(3+2)]}
]

Step 1:

[
3+2=5
]

Step 2:

[
8-5=3
]

Step 3:

[
5+3=8
]

Step 4:

[
20-8=12
]

# 11. Exponents (Indices)

Rules:

### Same Base

[
a^m\times a^n=a^{m+n}
]

Example:

[
2^3\times2^4=2^7=128
]

---

### Division

[
a^m\div a^n=a^{m-n}
]

Example:

[
5^7\div5^3=5^4=625
]

---

### Power of Power

[
(a^m)^n=a^{mn}
]

Example:

[
(3^2)^4=3^8
]

---

### Zero Power

[
a^0=1
]

Example:

[
7^0=1
]

---

### Negative Power

[
a^{-1}=\frac1a
]

Example:

[
2^{-3}=\frac18
]

---

# 12. Surds

A surd is a root that cannot be simplified into an integer.

Examples:

[
\sqrt2,\ \sqrt3,\ \sqrt5
]

Simplification:

[
\sqrt{72}
=\sqrt{36\times2}
=6\sqrt2
]
