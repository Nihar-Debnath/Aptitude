# Assertion → Example (or Claim → Evidence)

The idea is simple:

> **One sentence makes a claim (assertion), and the next sentence gives an example or proof of that claim.**

These two sentences usually stay together.

The options are:

The sentences are:

**A.** One has to see if this is just a bubble and if it will burst.

**B.** Software stocks have recently set the bourses on fire.

**C.** Companies like ABX Software have quoted a 150% rise.

**D.** The latest craze for Software shares led to a spurt in their prices.

---

## Step 1: Find the mandatory pair

### B

> Software stocks have recently set the bourses on fire.

This is a **general statement**.

### C

> Companies like ABX Software have quoted a 150% rise.

This gives a **specific example**.

So:

✅ **B → C** is a very strong pair.

---

## Step 2: What about D?

D says:

> The latest craze for Software shares led to a spurt in their prices.

This sentence explains **why** software stocks have become so popular.

Notice the flow:

> **Software stocks have recently set the bourses on fire.**
>
> **Why?**
>
> Because the craze for software shares caused their prices to shoot up.
>
> **Example:** ABX Software rose 150%.

So the natural flow is:

**B → D → C**

---

## Step 3: Where does A go?

A says:

> One has to see if **this** is just a bubble and if it will burst.

The word **"this"** refers to the whole phenomenon:

* software stocks rising,
* craze in the market,
* 150% gains.

So A is the **conclusion**.

It should come last.

---

## Final order

**B → D → C → A**

Which is:

✅ **Option A (BDCA)**

---

## Why wasn't B → C an immediate pair here?

This is an important lesson.

There are **two kinds of pairs**:

### 1. Immediate pair

The two sentences **must be adjacent**.

Example:

> Rahul bought a bike.
>
> He rides it every day.

You cannot insert another sentence between them.

---

### 2. Logical pair

The two sentences are related, but **another explanatory sentence may come in between**.

Here:

> Software stocks are doing well.
>
> (Explanation of why.)
>
> Example: ABX rose 150%.

So **B and C are related**, but **D naturally fits between them**.

---

## The deeper concept

This question is actually testing another common paragraph structure:

**General Statement → Reason → Example → Conclusion**

Let's map it:

* **B** = General statement
* **D** = Reason/Cause
* **C** = Example/Evidence
* **A** = Conclusion

So the structure is:

```text
General Statement
        ↓
Reason
        ↓
Example
        ↓
Conclusion
```

This is why **BDCA** is the best answer.

---

This is also a good reminder that **mandatory pairs are not always immediate pairs**. Sometimes the relationship is "these two ideas belong together," but another sentence is needed to connect them smoothly. In para jumbles, always ask:

* **Must these sentences be adjacent?** (Immediate pair)
* **Or are they just logically connected?** (Logical pair)

That's the difference that this question is teaching.
