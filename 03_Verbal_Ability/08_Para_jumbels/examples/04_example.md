# Why didn't we eliminate A or D yet?

Because **nothing has been violated**.

Sentence 1 is a perfectly valid opener:

> 1971 war changed the political geography of the subcontinent.

It introduces the topic.

Both options begin with it.

So we need another clue before eliminating either.

# What did we use?

We didn't read the whole paragraph.

We only used:

### Rule 1

**A paragraph cannot start with an unresolved reference.**

Examples:

* this ❌
* that ❌
* these ❌
* those ❌
* the event ❌ (refers to a previously mentioned event)
* the conflict ❌ (if not introduced)

🔥 **This is exactly how an aptitude expert thinks.**

They don't immediately solve the paragraph. They first ask:

> **"Which options are impossible?"**

Only after reducing the choices from **4 → 2** do they start looking for mandatory pairs, forward links, backward links, or the closing sentence. That's much faster and more reliable than trying to arrange all four sentences from the beginning.
