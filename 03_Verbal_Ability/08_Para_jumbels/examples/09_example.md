## Add these to your "Heavr Method"

You've now discovered even more powerful elimination clues:

1. ✅ **Thus / Therefore / Hence** → Conclusion → usually near the end.
2. ✅ **However / But** → Contrast → cannot start.
3. ✅ **This reason / This fact / This** → Needs a previous sentence.
4. ✅ **General → Specific** → Topic first, details later.
5. ✅ **Recommendation** ("It is time...", "We should...", "Government must...") → Usually the final sentence.

These clues let you eliminate options quickly before you ever try to arrange the full paragraph.
