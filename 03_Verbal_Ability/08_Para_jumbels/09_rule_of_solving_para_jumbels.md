# Para Jumble Solving Algorithm (MCQ)

## Step 1: Look at the options first. ✅

Don't read all the sentences first.

Instead, quickly scan the options and notice:

* Which sentence starts most often?
* Which sentence ends most often?
* Which sentence pairs repeat?

For your previous question:

```
A. BCAD
B. ADCB
C. ADBC
D. BADC
```

Immediately notice:

* B starts twice.
* A starts twice.

Now read only **A and B** first and decide which is a better opening sentence.

---

## Step 2: Find the General Sentence. ✅

Ask yourself:

> Which sentence introduces the topic?

General sentences usually:

* define something
* introduce a topic
* state a broad fact

Example:

> Offshore work means work done abroad.

This introduces the concept.

---

## Step 3: Find the sentence that naturally follows it. ✅

Ask:

* Does another sentence explain it?
* Contrast it?
* Give an example?
* Continue the definition?

Example:

> Offshore means work done abroad.

↓

> It is just the opposite in software companies.

This is the natural continuation.

---

## Step 4: Eliminate options. ✅

Don't try to build the whole paragraph.

Instead ask:

> Which options break this pair?

Previous question:

```
B → C
```

Only one option had BC together.

The answer became obvious.

---

## Step 5: Check the ending sentence.

Many paragraphs end with:

* conclusion
* result
* opinion
* recommendation
* future prediction

Words like:

* Therefore
* Hence
* Thus
* Finally
* Overall

often indicate the last sentence.

---

# Your strategy becomes:

```
1. Check options first.

↓

2. Find the opening/general sentence.

↓

3. Find its immediate continuation.

↓

4. Eliminate options.

↓

5. Verify the ending.
```

This is exactly how experienced aptitude trainers solve MCQ para jumbles—they don't try to mentally arrange every sentence from scratch.

---

# One improvement I'd add ⭐⭐⭐⭐⭐

Don't always look for the **general sentence** first.

Instead, look for the **strongest clue**.

Sometimes that's the general sentence, but sometimes it's something else.

The strongest clues are:

1. **Pronouns** (`he`, `she`, `it`, `this`, `they`)
2. **Connectors** (`however`, `therefore`, `moreover`, `instead`)
3. **General → Specific**
4. **Definition → Explanation**
5. **Cause → Effect**
6. **Example → Assertion**
7. **Chronological order**

Whichever clue is the strongest in that question, use it first.

---

## The final algorithm I'd recommend you memorize for TCS Ignite

```
STEP 1 → Check the options first.

STEP 2 → Find the opening sentence.

STEP 3 → Find the strongest mandatory pair.
         (Pronoun, General→Specific, Definition→Explanation,
          Cause→Effect, Assertion→Example, etc.)

STEP 4 → Eliminate options.

STEP 5 → Read the remaining option once to confirm the paragraph flows naturally.
```

If you follow this sequence consistently, you'll solve most TCS-style para jumbles much faster and with fewer mistakes than trying to arrange all the sentences manually.
