# What is a Pair Sentence?

A **pair sentence** means:

> **Two sentences that must come together in the paragraph.**

Instead of arranging all 4–5 sentences, first identify **which two sentences are inseparable**.

For example:

P. Rahul bought a car.

Q. He drove it to Kolkata.

Here,

**P → Q**

must stay together because:

* "He" = Rahul
* "it" = car

You can't separate them.

# Second Example

Now the question changes.

It says

> **R is followed by S.**

Notice something?

It **doesn't** say

> immediately followed.

That changes everything.

Now

R and S

can have sentences in between.

Like

```
R P Q S
```

This is still correct because

R comes before S.

---

Let's check.

### Option A

```
S P Q R
```

R comes after S.

❌ Wrong

---

### Option B

```
S R P Q
```

Again,

S comes first.

❌ Wrong

---

### Option C

```
P Q R S
```

R comes before S.

✅ Correct

---

### Option D

```

```

R

↓

P

↓

S

Still correct because

R is before S.

✅ Also possible.

That's why the teacher writes:

> **We can read the question from sequence A & B for correct answer.**

Meaning:

You now need to actually read the sentences because **two options satisfy the condition**.

# Real Para Jumble Example

Imagine these sentences.

A. The company launched a new phone.

B. It received excellent reviews.

C. Sales increased rapidly.

D. Therefore, profits doubled.

---

Can you spot the pair?

A introduces

**the new phone.**

B starts with

**It**

"It" refers to

the new phone.

So

```
A → B
```

is a fixed pair.

Now look at options.

1.

```
A B C D
```

2.

```
B A C D
```

3.

```
A C B D
```

4.

```
C A B D
```

Only Option 1 keeps

```
A B
```

together.

You don't even need to arrange everything.

Answer found.

# How do you identify pair sentences?

Look for these clues:

### 1. Pronoun Pair ⭐⭐⭐⭐⭐

```
Rahul bought a bike.
He rode it home.
```

Pair:

```
Rahul → He
```

---

### 2. Cause → Effect

```
It rained heavily.

The roads became flooded.
```

Pair.

---

### 3. Question → Answer

```
Why do birds migrate?

They migrate to find food.
```

Pair.

---

### 4. Definition → Explanation

```
Artificial Intelligence is...

It enables machines to...
```

Pair.

---

### 5. General → Example

```
India has many festivals.

For example, Diwali...
```

Pair.

---

### 6. Contrast

```
Many people liked the movie.

However, critics disagreed.
```

Pair.

---

### 7. Sequence Words

```
First

Next

Then

Finally
```

These naturally create pairs.

# TCS Ignite Trick ⭐⭐⭐⭐⭐

In TCS, don't try to arrange all four or five sentences immediately.

Instead, follow this process:

1. **Find the opening sentence.**
2. **Find one or two fixed pairs.**
3. **Check the options and eliminate those that break the pairs.**
4. **Read only the remaining one or two options carefully.**

This is much faster than constructing the entire paragraph from scratch.
