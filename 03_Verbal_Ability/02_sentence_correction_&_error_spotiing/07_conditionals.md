# What are Conditionals?

A **conditional sentence** expresses:

> **If this happens, then that happens.**

It has **two parts**:

```text
IF clause (condition) + Main clause (result)
```

Example:

> If you study, you will pass.

Here,

* Condition = you study
* Result = you will pass

Think of it like a machine:

```text
Condition  ─────────► Result

If you study ───────► You will pass
```

---

# Why are there different types?

Not every condition is the same.

Sometimes we talk about:

* Facts
* Future possibilities
* Imaginary situations
* Regrets about the past

English has a different conditional for each.

---

# Type 0 Conditional (Universal Truth)

## Structure

```text
If + Present Simple, Present Simple
```

Formula

```text
If + V1, V1
```

---

## Use

Things that are **always true**.

Scientific facts.

Habits.

General truths.

---

Examples

> If you heat water to 100°C, it boils.

Always true.

---

> If you don't sleep, you feel tired.

Always true.

---

> If ice melts, it becomes water.

Always true.

---

Memory

```text
Truth + Truth

Present → Present
```

---

# Type 1 Conditional (Real Future Possibility)

## Structure

```text
If + Present Simple, will + V1
```

Formula

```text
If + V1, will + V1
```

---

## Use

Something **may happen in the future**.

There is a real chance.

---

Examples

> If it rains, we will stay home.

Maybe it rains.

Maybe it doesn't.

---

> If you work hard, you will succeed.

Possible.

---

> If you call me, I'll help you.

---

Timeline

```text
Present -------- Future

If X happens
        ↓
Y will happen
```

---

Memory

```text
Possible Future

Present → Will
```

---

# Type 2 Conditional (Imaginary Present/Future)

This is where most students get confused.

---

## Structure

```text
If + Past Simple, would + V1
```

Formula

```text
If + V2, would + V1
```

---

## Use

Things that are

* imaginary
* unreal
* unlikely

---

Example

> If I were rich, I would buy a Ferrari.

Am I rich?

No.

It's imagination.

---

Another

> If I knew French, I would work in Paris.

Do I know French?

No.

---

Timeline

```text
Present Reality

Reality:
I am poor

Imagine:
If I were rich...
```

---

Memory

```text
Imaginary Present

Past → Would
```

Notice:

The past tense **doesn't mean past time**.

It means

> "This is not true."

---

# Important Rule

With **be**, use

> **were**

for all subjects in formal English.

Not

❌ If I was rich...

Better

✅ If I were rich...

---

# Type 3 Conditional (Impossible Past)

This expresses regret.

---

## Structure

```text
If + Past Perfect, would have + V3
```

Formula

```text
If + had + V3,
would have + V3
```

---

Use

Things that **cannot be changed**.

The past is over.

---

Example

> If I had studied, I would have passed.

Did I study?

No.

Can I change it?

No.

---

Another

> If she had left early, she would have caught the train.

Reality

She didn't leave early.

So she missed the train.

---

Timeline

```text
Past

Wrong decision
        ↓
Regret today
```

---

Memory

```text
Impossible Past

Had + V3
↓

Would have + V3
```

---

# Mixed Conditionals

Sometimes we mix time.

---

Example

> If I had studied medicine, I would be a doctor now.

Past condition

↓

Present result

---

Structure

```text
If + had + V3,
would + V1
```

---

Example

> If I had listened to my teacher, I would know this now.

Past mistake.

Present consequence.

---

# Common Exam Errors

## Error 1

❌ If you study, you would pass.

Wrong.

Because

Present

*

Would

Don't match.

Correct

> If you study, you will pass.

OR

> If you studied, you would pass.

---

## Error 2

❌ If I knew the answer, I will tell you.

Wrong.

Correct

> If I knew the answer, I would tell you.

---

## Error 3

❌ If he had worked harder, he would pass.

Wrong.

Should be

> would have passed

---

## Error 4

❌ If I was you...

Formal English

> If I were you...

---

# Unless

"Unless" means

> If not

Example

> Unless you study, you will fail.

Same as

> If you do not study, you will fail.

---

# Even If

Means

"No matter whether."

Example

> Even if it rains, I'll go.

---

# Provided That

Means

"If."

Example

> I'll help you provided that you help me.

---

# In Case

Means

"As a precaution."

Example

> Take an umbrella in case it rains.

Not the same as "if."

---

# Suppose / Supposing

Means

"What if?"

Example

> Suppose you won a lottery.

---

# As Long As

Means

"If."

Example

> You can stay as long as you behave.

---

# Only If

Means

Only under this condition.

Example

> You can enter only if you have a ticket.

---

# Whether...or

Not a conditional.

Example

> Whether you come or not, I'll go.

---

# The Complete Table

| Type      | Structure                       | Meaning                    | Example                                            |
| --------- | ------------------------------- | -------------------------- | -------------------------------------------------- |
| **0**     | If + Present → Present          | Facts, truths              | If you heat water, it boils.                       |
| **1**     | If + Present → Will + V1        | Real future possibility    | If you study, you will pass.                       |
| **2**     | If + Past → Would + V1          | Imaginary present/future   | If I were rich, I would travel.                    |
| **3**     | If + Had + V3 → Would have + V3 | Impossible past, regret    | If I had studied, I would have passed.             |
| **Mixed** | If + Had + V3 → Would + V1      | Past cause, present result | If I had worked harder, I would be successful now. |

# Exam Shortcut (Very Important)

Whenever you see **if**, immediately look for the verb pattern:

| If-clause | Main clause                  |
| --------- | ---------------------------- |
| Present   | Present → **Type 0**         |
| Present   | Will + V1 → **Type 1**       |
| Past      | Would + V1 → **Type 2**      |
| Had + V3  | Would have + V3 → **Type 3** |

If the two halves don't match the intended type, there's likely an error. This is one of the most common patterns in **error spotting**, **sentence correction**, and **fill-in-the-blanks** questions.
