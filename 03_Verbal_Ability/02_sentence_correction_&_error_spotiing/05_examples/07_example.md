# Here's a useful lesson for you

When solving **Error Spotting**, ask yourself:

> **Is this grammatically impossible, or just less natural?**

If it's **grammatically impossible**, mark it as an error.

Example:

* ❌ Everyone **were** happy.
* ❌ He **don't** know.
* ❌ She **have** a car.

These are definite grammar mistakes.

If it's only **less common** or **less natural**, many exams **won't** count it as an error.
