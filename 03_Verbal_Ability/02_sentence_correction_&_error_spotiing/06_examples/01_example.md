# Question

> No sooner did my friend see his teacher **(1)** / when he **(2)** / stopped copying. **(3)** / No error **(4)**

Let's solve it like an examiner.

---

# Step 1: Look for special grammar structures

As soon as you see:

> **No sooner**

💡 Your brain should immediately recall:

```text
No sooner + had + Subject + V3 + than + Subject + V2
```

This is a fixed structure.

---

# Step 2: Compare the sentence with the rule

### Rule

```text
No sooner + had + Subject + V3 + than + Subject + V2
```

### Given

```text
No sooner + did + my friend + see + his teacher + when + he + stopped
```

Two things are wrong!

---

# Error 1

The sentence says:

> **did**

But after **No sooner**, we need:

> **had**

So

❌ did

✅ had

---

# Error 2

The sentence says:

> **when**

But the fixed pair is

```text
No sooner ..... than
```

not

```text
No sooner ..... when
```

So

❌ when

✅ than

---

# Which part should you mark?

The sentence is divided as:

### Part (1)

> No sooner did my friend see his teacher

### Part (2)

> when he

### Part (3)

> stopped copying.

Since the options allow **only one error**, you choose the error that the examiner intended to test.

Here, **Part (2)** contains:

> **when**

which should be **than**.

So the expected answer is:

✅ **Option B (Part 2)**

---

# But what about "did"?

Excellent observation!

In modern English grammar,

> **No sooner did I see... than...**

is sometimes accepted because "did + base verb" is grammatically possible in certain contexts.

However, in **competitive exams (SSC, Banking, CDS, etc.)**, the tested and expected structure is:

> **No sooner had + Subject + V3 + than...**

The exam usually focuses on the connector:

> ❌ when

> ✅ than

That's why the official answer is generally **Part (2)**.

---

# Correct Sentence (Formal Exam English)

> **No sooner had my friend seen his teacher than he stopped copying.**

Notice all three corrections:

* **did** → **had**
* **see** → **seen** (because after *had*, we need V3)
* **when** → **than**

---

# Exam Tip ⭐

Whenever you see one of these phrases:

| You see... | Your brain should say... |
| ---------- | ------------------------ |
| No sooner  | **than**                 |
| Hardly     | **when**                 |
| Scarcely   | **when**                 |
| Barely     | **when**                 |

These are called **correlative conjunctions** or **fixed pairs**, and exams ask them repeatedly.
