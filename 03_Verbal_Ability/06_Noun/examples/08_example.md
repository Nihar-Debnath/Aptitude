Excellent. This is a **pure possessive noun question**, and it's one of the most common patterns in placement exams.

Let's solve it step by step.

---

# Question

Which sentence is correct?

### A)

> I went to **Girls's hostel.**

### B)

> I went to **Girl's hostel.**

### C)

> I went to **Girls' hostel.**

---

# Step 1: Ask yourself

How many girls are we talking about?

A **girls' hostel** is a hostel where **many girls** stay.

Not one girl.

So the owner is

```text
Girls
```

Plural.

---

# Step 2: Find the plural noun

Singular

```text
Girl
```

Plural

```text
Girls
```

Notice

Girls already ends with **s**.

---

# Step 3: Apply the possessive rule

Remember the rule.

| Owner | Possessive |
| ----- | ---------- |
| Girl  | Girl's     |
| Girls | Girls'     |

If the plural noun already ends with **s**,

just add

```text
'
```

Not

```text
's
```

---

# Now check every option

## Option A

> Girls's hostel

Break it.

```text
Girls

+

's
```

But

Girls already ends in **s**.

So this becomes

```text
Girls's
```

❌ Wrong.

---

## Option B

> Girl's hostel

Meaning

One girl owns the hostel.

Imagine

```text
One Girl

↓

Hostel
```

That means

The hostel belongs to **one girl**.

That is not what we mean.

So

❌ Wrong.

---

## Option C

> Girls' hostel

Break it.

```text
Girls

+

'
```

Meaning

A hostel for girls.

This is exactly what we want.

✅ Correct.

# The Complete Rule

| Owner    | Possessive |
| -------- | ---------- |
| Girl     | Girl's     |
| Girls    | Girls'     |
| Boy      | Boy's      |
| Boys     | Boys'      |
| Student  | Student's  |
| Students | Students'  |
| Woman    | Woman's    |
| Women    | Women's    |
| Child    | Child's    |
| Children | Children's |

# ⭐ One More Thing (Very Important)

There's a subtle meaning difference that placement exams sometimes test:

### Girls' hostel

Means:

> A hostel **for girls** (the standard expression).

### Girl's hostel

Means:

> A hostel belonging to **one specific girl**.

Grammatically possible, but it's **not** the meaning we intend when we talk about a hostel for female students.

* **girls** = plural noun ending in **s**
