# What is a Possessive Noun?

A **possessive noun** shows:

* Ownership
* Relationship
* Belonging

Ask yourself:

> **Whose is it?**

If the sentence answers **whose**, it usually uses a possessive noun.

---

## Example 1

> This is **Rahul's** book.

Question:

Whose book?

Answer:

Rahul's.

So **Rahul's** is a possessive noun.

---

## Example 2

> This is **my father's** car.

Question:

Whose car?

Answer:

My father's.

---

# Rule 1: Singular Noun → Add **'s**

This is the most important rule.

| Singular Noun | Possessive |
| ------------- | ---------- |
| Rahul         | Rahul's    |
| Boy           | Boy's      |
| Girl          | Girl's     |
| Dog           | Dog's      |

Examples:

> Rahul's laptop **is** expensive.

| Noun  | Possessive | Verb |
| ----- | ---------- | ---- |
| Rahul | Rahul's    | is   |

---

> The dog's tail **is** long.

Question:

Whose tail?

Answer:

The dog's.

---

# Rule 2: Plural Nouns Ending in **s**

If the plural noun already ends in **s**,

add only an apostrophe (**'**).

| Plural Noun | Possessive |
| ----------- | ---------- |
| Students    | Students'  |
| Teachers    | Teachers'  |
| Boys        | Boys'      |
| Girls       | Girls'     |

Example:

> The students' classroom **is** clean.

Question:

Whose classroom?

Answer:

The students'.

Notice:

We did **not** add another **s**.

---

# Compare

### One student

> The student's bag.

One student owns the bag.

---

### Many students

> The students' bags.

Many students own the bags.

---

# Rule 3: Irregular Plurals

Some plurals don't end in **s**.

Examples:

* children
* men
* women
* people
* mice

Since they don't end in **s**, add **'s**.

| Plural   | Possessive                 |
| -------- | -------------------------- |
| Children | Children's                 |
| Men      | Men's                      |
| Women    | Women's                    |
| People   | People's                   |
| Mice     | Mice's (rare, but correct) |

Examples:

> The children's toys **are** everywhere.

> The men's room **is** upstairs.

---

| Noun     | Possessive |
| -------- | ---------- |
| Boy      | Boy's      |
| Boys     | Boys'      |
| Child    | Child's    |
| Children | Children's |

This table alone solves many exam questions.

# Rule 4: Names Ending in S

This confuses almost everyone.

Example:

James

There are **two accepted styles**.

### Style 1 (Most common today)

> James's book

### Style 2

> James' book

Both are accepted by different style guides.

For placement exams, if both appear, **James's** is usually preferred unless the exam specifies a style guide.

---

# Rule 5: Joint Possession

When **two people own one thing together**, add **'s** only to the last name.

Example:

> Rahul and Amit's house.

Meaning:

They own **one house together**.

---

Diagram:

```text
Rahul + Amit
      │
   One House
```

---

# Rule 6: Separate Possession

If each person owns something separately,

add **'s** to both.

Example:

> Rahul's and Amit's laptops.

Meaning:

Rahul has one laptop.

Amit has another laptop.

---

Diagram:

```text
Rahul → Laptop

Amit → Laptop
```

---

# Rule 7: Possessive of Time

English also uses possessives for time.

Examples:

A day's work

A week's holiday

A month's salary

A year's experience

Notice:

Time can own something grammatically.

# Placement Exam Memory Trick

Whenever you see an apostrophe (`'`), ask yourself **two questions**:

1. **Whose is it?** (ownership)
2. **Is the owner singular or plural?**

Then apply this:

* **Singular owner** → add **'s** (`boy's`, `Rahul's`)
* **Plural owner ending in s** → add only **'** (`students'`, `teachers'`)
* **Irregular plural owner** → add **'s** (`children's`, `men's`)

This simple process will help you solve almost every possessive noun question in placement exams.
