# Step 1: Singular vs Plural

Very simple.

| Singular | Plural     |
| -------- | ---------- |
| one book | two books  |
| one pen  | five pens  |
| one dog  | three dogs |

Rule

```text
One = Singular

More than one = Plural
```

# Step 2: Regular Plurals

## Rule 1

Just add **S**

| Singular | Plural  |
| -------- | ------- |
| Car      | Cars    |
| Pen      | Pens    |
| Boy      | Boys    |
| Laptop   | Laptops |

Very easy.

---

## Rule 2

Ends with

```
s
ss
sh
ch
x
z
```

Add **ES**

| Singular | Plural  |
| -------- | ------- |
| Bus      | Buses   |
| Class    | Classes |
| Box      | Boxes   |
| Dish     | Dishes  |
| Watch    | Watches |
| Buzz     | Buzzes  |

### Trick

Remember

> **SS SH CH X Z**

Whenever you see these endings,

add **ES**

# Step 3: Words ending in Y

This confuses everyone.

There are TWO rules.

---

## Rule A

Consonant + Y

Change

```
Y → IES
```

Examples

| Singular | Plural    |
| -------- | --------- |
| Baby     | Babies    |
| City     | Cities    |
| Lady     | Ladies    |
| Country  | Countries |

Notice

```
babY

↓

babIES
```

---

## Rule B

Vowel + Y

Only add S.

| Singular | Plural  |
| -------- | ------- |
| Boy      | Boys    |
| Toy      | Toys    |
| Monkey   | Monkeys |
| Key      | Keys    |

Why?

Because

```
boY

before Y is O

O is vowel

↓

Boys
```

# Placement Trick

Which is correct?

A)

Monkeies

B)

Monkeys

Answer?

Many students choose A.

Correct answer:

✅ Monkeys

because

```
e + y

E is vowel

Only S
```

# Step 4: Ending with F or FE

Sometimes

```
F → VES
```

Examples

| Singular | Plural |
| -------- | ------ |
| Knife    | Knives |
| Wife     | Wives  |
| Wolf     | Wolves |
| Life     | Lives  |
| Leaf     | Leaves |

---

But not always.

Examples

| Singular | Plural  |
| -------- | ------- |
| Roof     | Roofs   |
| Chief    | Chiefs  |
| Belief   | Beliefs |
| Cliff    | Cliffs  |

These are exceptions.

You have to remember them.

Some words never change.

# Step 8: Always Singular

These nouns look plural or abstract but take a singular verb.

Examples:

* Information
* Advice
* Furniture
* Luggage
* Equipment
* Knowledge
* News

Correct:

> The information **is** useful.

Wrong:

> The information **are** useful.

---

# Step 9: Always Plural

These always take a plural verb.

Examples:

* Scissors
* Trousers
* Pants
* Shorts
* Jeans
* Spectacles
* Glasses

Correct:

> My scissors **are** sharp.

Wrong:

> My scissors **is** sharp.

---

# Step 10: Collective Nouns

These represent a group but are usually treated as singular in American English.

Examples:

Team

Family

Committee

Audience

Class

Correct:

> The team **is** playing well.

Not

> The team are...

(In British English, both can be correct depending on the meaning.)

Choose the correct sentence.

✅ B

"Police" is treated as plural.

Although "news" ends with **s**, it is singular.

# Where can you learn ALL singular → plural forms?

No one memorizes every English noun—there are hundreds of thousands of them. Instead, focus on the common patterns and exceptions.

Here are the best resources:

### 1. Cambridge Dictionary ⭐⭐⭐⭐⭐

* Every noun entry tells you its plural form (if any).
* It also tells you if a noun is countable `[C]` or uncountable `[U]`.

Example:

* advice `[U]`
* child → children

### 2. Oxford Learner's Dictionary ⭐⭐⭐⭐⭐

Also shows:

* plural forms
* countable/uncountable
* pronunciation
* examples

### 3. Merriam-Webster

Very good for irregular plurals and American English.
