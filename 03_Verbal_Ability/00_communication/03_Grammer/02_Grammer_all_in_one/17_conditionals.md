## What are Conditionals?

**Conditionals** are sentences that talk about a **condition and its result**.

The basic idea is:

> **If X happens, Y happens.**

For example:

> **If it rains, I will stay home.**

Here:

* **If it rains** → condition
* **I will stay home** → result

So conditionals are basically **"if" sentences**.

---

# 1. Basic structure

A conditional usually has two parts:

### Condition (if-clause) + Result (main clause)

> **If I study, I will pass.**

**If I study** = condition
**I will pass** = result

You can also reverse them:

> **I will pass if I study.**

The meaning is the same.

### Comma rule

When the **if-clause comes first**, use a comma:

> If I study, I will pass. ✅

When it comes second, usually no comma:

> I will pass if I study. ✅

---

# 2. There are 5 important types

For English grammar, learn these:

| Type                   | Main idea                                       | Example                                      |
| ---------------------- | ----------------------------------------------- | -------------------------------------------- |
| **Zero Conditional**   | General truth/fact                              | If you heat ice, it melts.                   |
| **First Conditional**  | Real/possible future                            | If I study, I will pass.                     |
| **Second Conditional** | Unreal/hypothetical present/future              | If I studied, I would pass.                  |
| **Third Conditional**  | Unreal past                                     | If I had studied, I would have passed.       |
| **Mixed Conditional**  | Past condition + present result (or vice versa) | If I had studied, I would be successful now. |

Let's understand each one properly.

---

# 3. Zero Conditional

Used for:

* general truths
* facts
* scientific facts
* things that **always/usually happen**

### Structure

> **If + present simple, present simple**

### Examples

> If you heat water to 100°C, it boils.

> If you don't eat, you get hungry.

> If it rains, the ground gets wet.

The important thing is that this isn't about one particular future situation.

It means:

> **Whenever this condition happens, this result happens.**

### Exam rule

**Zero conditional:**

> `If + V1, V1`

Example:

> If you heat ice, it **melts**.

Not:

> If you heat ice, it **will melt** ❌

If you're stating a general scientific fact, use the zero conditional.

---

# 4. First Conditional

Used for a **real or possible situation in the future**.

You believe the condition can actually happen.

### Structure

> **If + present simple, will + V1**

Example:

> If I study hard, I will pass the exam.

Meaning:

> Maybe I will study hard → then I will probably pass.

Other examples:

> If it rains tomorrow, I will stay home.

> If she comes, I will talk to her.

> If you practice English, your English will improve.

### Important rule

After **if**, don't normally use **will** for the condition.

❌ If I **will study**, I will pass.

✅ If I **study**, I will pass.

Think:

> **IF = present**
> **RESULT = will**

---

# 5. Second Conditional

This is where things become more interesting.

The second conditional talks about:

* imaginary situations
* unlikely situations
* hypothetical situations
* things that aren't true now

### Structure

> **If + past simple, would + V1**

Example:

> If I **had** more money, I **would buy** a car.

The speaker probably doesn't have enough money.

So this is hypothetical.

Compare:

### First conditional:

> If I **have** enough money, I **will buy** a car.

= Maybe I'll have enough money.

### Second conditional:

> If I **had** enough money, I **would buy** a car.

= I don't have enough money now; I'm imagining it.

---

# 6. The famous "were" rule

This connects to what you asked earlier about **subjunctive mood**.

For hypothetical/unreal situations, we commonly use:

> **were**

with **all persons**.

### Example:

> If I **were** rich, I would travel the world.

> If he **were** here, he would help us.

> If she **were** my teacher, I would ask her.

> If they **were** here, we would start.

Notice:

| Subject | Correct hypothetical form |
| ------- | ------------------------- |
| I       | were                      |
| You     | were                      |
| He      | were                      |
| She     | were                      |
| It      | were                      |
| We      | were                      |
| They    | were                      |

So:

> **If I were you, I would study.** ✅

This is a very common expression.

### Why "were"?

Because this is an **unreal/hypothetical situation**, not ordinary past tense.

> I was tired yesterday.
> = Real past → **was**

> If I were rich...
> = Imaginary → **were**

---

# 7. Third Conditional

Now we're talking about the **past**.

It describes something that:

> **didn't happen in the past**

and imagines what the result would have been.

### Structure

> **If + past perfect, would have + V3**

Example:

> If I **had studied**, I **would have passed**.

Reality:

> I didn't study → I didn't pass.

We're imagining a different past.

---

### Another example

> If she had left earlier, she would have caught the train.

Reality:

> She didn't leave earlier.
> She missed the train.

We're changing the past **in our imagination**.

---

# 8. Compare all three

This is extremely important.

### First conditional

> If I **study**, I **will pass**.

Meaning:

**Possible future**

Maybe I will study.

---

### Second conditional

> If I **studied**, I **would pass**.

Meaning:

**Hypothetical/unlikely present or future**

I'm imagining the situation.

---

### Third conditional

> If I **had studied**, I **would have passed**.

Meaning:

**Impossible past**

The exam already happened. I didn't study, so I didn't pass.

---

# 9. The easiest way to remember them

Think about **time + reality**:

| Conditional | Time           | Reality                     |
| ----------- | -------------- | --------------------------- |
| **Zero**    | Present        | Fact/general truth          |
| **First**   | Future         | Real/possible               |
| **Second**  | Present/Future | Unreal/hypothetical         |
| **Third**   | Past           | Unreal/impossible to change |

---

# 10. Formula cheat sheet

Memorize these:

### Zero

> **If + V1 → V1**

> If you heat ice, it melts.

### First

> **If + V1 → will + V1**

> If I study, I will pass.

### Second

> **If + V2 → would + V1**

> If I studied, I would pass.

### Third

> **If + had + V3 → would have + V3**

> If I had studied, I would have passed.

---

# 11. Don't confuse V2 and V3

This is important.

For **second conditional**:

> If I **studied**, I would pass.

**studied = V2**

For **third conditional**:

> If I **had studied**, I would have passed.

**studied = V3**

For regular verbs, V2 and V3 look the same:

> study → studied → studied

But with irregular verbs you can see the difference:

> go → went → gone

### Second:

> If I **went** there, I would meet him.

### Third:

> If I **had gone** there, I would have met him.

---

# 12. "Would" is not normally used after IF

This is one of the biggest exam traps.

❌ If I **would study**, I would pass.

✅ If I **studied**, I would pass.

❌ If I **would have studied**, I would have passed.

✅ If I **had studied**, I would have passed.

The usual pattern is:

> **IF → condition tense**
> **main clause → would/will**

---

# 13. Other words can replace "if"

Conditionals aren't limited to **if**.

### Unless = if...not

> Unless you study, you will fail.

= If you **don't** study, you will fail.

### As long as = provided that

> You can go as long as you finish your work.

### Provided that

> You can use my laptop provided that you take care of it.

### In case

> Take an umbrella in case it rains.

---

# 14. "Unless" is a common exam trap

**Unless = if not**

So:

> Unless you work hard, you won't succeed.

means:

> If you **don't** work hard, you won't succeed.

Don't normally use another negative after unless:

❌ Unless you **don't** study, you will fail.

That changes the meaning and is generally not what you want.

---

# 15. Conditional sentences can be questions

> What will you do if you fail?

> What would you do if you were rich?

> What would you have done if you had failed?

Notice the same conditional patterns.

---

# 16. Mixed Conditionals

These combine different times.

The most common one:

### Past condition → present result

> If I **had studied** harder, I **would have a better job now**.

Reality:

I didn't study hard in the past → my situation is worse now.

So:

**past condition**

> had studied

*

**present result**

> would have

---

Another:

> If I had gone to college earlier, I would be graduating now.

Past decision → present consequence.

---

# 17. A very useful comparison

Imagine your exam is tomorrow.

### Zero

> If I study, I understand the material better.

General observation.

### First

> If I study tonight, I will pass tomorrow's test.

Possible future.

### Second

> If I studied more, I would feel confident.

Hypothetical/unreal situation.

### Third

> If I had studied yesterday, I would have felt confident today.

Changing something that happened in the past.

---

# 18. The biggest pattern to memorize

Think of the condition as moving backward in tense:

**First:**

> If + **present** → **will**

**Second:**

> If + **past** → **would**

**Third:**

> If + **past perfect** → **would have**

So:

> **Present → will**
> **Past → would**
> **Past perfect → would have**

That's the core of conditional grammar.

### One-line definition

> **A conditional sentence expresses a condition and the result that depends on that condition.**

And for your grammar/exam preparation, the **four formulas you should know by heart** are:

```text
ZERO:
If + Present Simple → Present Simple

FIRST:
If + Present Simple → will + V1

SECOND:
If + Past Simple → would + V1

THIRD:
If + Past Perfect → would have + V3
```

The **Second Conditional + "were" rule** and the **Third Conditional** are especially important for error detection questions.
