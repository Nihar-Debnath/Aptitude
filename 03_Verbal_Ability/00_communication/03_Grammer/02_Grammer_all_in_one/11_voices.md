Absolutely. **Voice** is an important grammar topic, especially for verbal-ability questions. The good news is that once you understand the basic structure, most voice questions become mechanical.

# Voice in English Grammar

**Voice tells us whether the subject is doing the action or receiving the action.**

There are mainly **two voices**:

1. **Active Voice**
2. **Passive Voice**

---

# 1. Active Voice

In **Active Voice**, the subject **does the action**.

### Basic structure

**Subject + Verb + Object**

Example:

> Ram eats a mango.

* **Ram** → Subject
* **eats** → Verb
* **a mango** → Object

Ram is **doing** the action.

So this is **Active Voice**.

### More examples

* She writes a letter.
* The boy kicked the ball.
* They built a house.
* I completed the work.
* The teacher teaches English.

In all of these, the subject performs the action.

---

# 2. Passive Voice

In **Passive Voice**, the subject **receives the action**.

Example:

Active:

> Ram eats a mango.

Passive:

> A mango is eaten by Ram.

Notice what happened:

| Active      | Passive         |
| ----------- | --------------- |
| Ram         | A mango         |
| does action | receives action |
| eats        | is eaten        |
| a mango     | by Ram          |

So:

**Active:** Subject → does action
**Passive:** Subject → receives action

---

# The Most Important Formula

Remember this:

### Active

**Subject + Verb + Object**

### Passive

**Object + Helping Verb + V3 + by + Subject**

For example:

> Ram writes a letter.

Active:

**Ram + writes + a letter**

Passive:

**A letter + is + written + by Ram.**

---

# 3. What is V1, V2 and V3?

You MUST understand verb forms for passive voice.

| Form | Meaning         | Example |
| ---- | --------------- | ------- |
| V1   | Base form       | write   |
| V2   | Past            | wrote   |
| V3   | Past participle | written |

More:

| V1    | V2    | V3      |
| ----- | ----- | ------- |
| eat   | ate   | eaten   |
| go    | went  | gone    |
| do    | did   | done    |
| see   | saw   | seen    |
| take  | took  | taken   |
| make  | made  | made    |
| write | wrote | written |
| break | broke | broken  |
| speak | spoke | spoken  |
| give  | gave  | given   |

### VERY IMPORTANT

**Passive voice always uses V3.**

Examples:

❌ A letter is wrote by him.
✅ A letter is **written** by him.

❌ The work was did by me.
✅ The work was **done** by me.

---

# 4. The Golden Rule of Passive Voice

When changing Active → Passive:

### Step 1

Find the **object**.

### Step 2

Move the object to the beginning.

### Step 3

Choose the correct **helping verb**.

### Step 4

Change the main verb to **V3**.

### Step 5

Add **by + subject** if necessary.

---

# Example

### Active:

> The boy kicked the ball.

### Step 1 — Find object

What did the boy kick?

**the ball**

### Step 2 — Move object

> The ball...

### Step 3 — Helping verb

"Kicked" is simple past.

For singular **ball**, use **was**.

> The ball was...

### Step 4 — V3

kick → kicked

> The ball was kicked...

### Step 5

> The ball was kicked by the boy.

Done.

# 5. Active → Passive for All Tenses

This is the **most important part for exams**.

---

## A. Simple Present

### Active

**Subject + V1/V1+s + Object**

> She writes a letter.

### Passive

**Object + is/am/are + V3 + by + Subject**

> A letter is written by her.

### Examples

> He plays cricket.

→ Cricket **is played** by him.

> They clean the room.

→ The room **is cleaned** by them.

---

# B. Present Continuous

### Active

**Subject + is/am/are + V-ing + Object**

> She is writing a letter.

### Passive

**Object + is/am/are + being + V3 + by + Subject**

> A letter is being written by her.

### Key word:

**being**

Present Continuous Passive =

**is/am/are + being + V3**

Example:

> They are building a house.

→ A house **is being built** by them.

---

# C. Present Perfect

### Active

**Subject + has/have + V3 + Object**

> She has written a letter.

### Passive

**Object + has/have + been + V3 + by + Subject**

> A letter has been written by her.

### Key word:

**been**

Example:

> They have completed the work.

→ The work **has been completed** by them.

---

# D. Simple Past

### Active

**Subject + V2 + Object**

> She wrote a letter.

### Passive

**Object + was/were + V3 + by + Subject**

> A letter was written by her.

Example:

> They built a house.

→ A house **was built** by them.

---

# E. Past Continuous

### Active

**Subject + was/were + V-ing + Object**

> She was writing a letter.

### Passive

**Object + was/were + being + V3 + by + Subject**

> A letter was being written by her.

### Key:

**was/were + being + V3**

Example:

> They were repairing the car.

→ The car **was being repaired** by them.

---

# F. Past Perfect

### Active

**Subject + had + V3 + Object**

> She had written a letter.

### Passive

**Object + had + been + V3 + by + Subject**

> A letter had been written by her.

Example:

> They had completed the work.

→ The work **had been completed** by them.

---

# G. Simple Future

### Active

**Subject + will + V1 + Object**

> She will write a letter.

### Passive

**Object + will + be + V3 + by + Subject**

> A letter will be written by her.

### Key:

**will + be + V3**

Example:

> They will complete the work.

→ The work **will be completed** by them.

---

# H. Future Perfect

### Active

**Subject + will have + V3 + Object**

> She will have written a letter.

### Passive

**Object + will have been + V3 + by + Subject**

> A letter will have been written by her.

### Key:

**will have been + V3**

---

# Master Table

This is worth memorizing:

| Tense              | Active            | Passive                |
| ------------------ | ----------------- | ---------------------- |
| Simple Present     | V1                | is/am/are + V3         |
| Present Continuous | is/am/are + V-ing | is/am/are + being + V3 |
| Present Perfect    | has/have + V3     | has/have + been + V3   |
| Simple Past        | V2                | was/were + V3          |
| Past Continuous    | was/were + V-ing  | was/were + being + V3  |
| Past Perfect       | had + V3          | had + been + V3        |
| Simple Future      | will + V1         | will + be + V3         |
| Future Perfect     | will have + V3    | will have been + V3    |

---

# 6. Tenses That Normally Don't Have Passive Forms

For competitive exams, remember that these are generally **not used in passive voice**:

* Present Perfect Continuous
* Past Perfect Continuous
* Future Continuous
* Future Perfect Continuous

Their passive forms are theoretically possible in some constructions but are extremely awkward and generally avoided.

For aptitude/grammar questions, **don't waste time memorizing them.**

# 7. What Happens to Pronouns?

This is VERY important.

When the subject moves after **by**, its pronoun changes to the **object form**.

### Subject → Object

| Subject | Object |
| ------- | ------ |
| I       | me     |
| we      | us     |
| you     | you    |
| he      | him    |
| she     | her    |
| it      | it     |
| they    | them   |
| who     | whom   |

Example:

> **She** writes a letter.

→ A letter is written by **her**.

Not:

❌ by she

---

### More examples

> He helps me.

→ I am helped by **him**.

> They invited us.

→ We were invited by **them**.

> I completed the work.

→ The work was completed by **me**.

---

# 8. "By" Is Not Always Necessary

You don't always need to mention the original subject.

Example:

> Someone stole my phone.

Passive:

> My phone was stolen.

We don't necessarily need:

> My phone was stolen by someone.

Because **someone** isn't important.

Similarly:

> People speak English all over the world.

→ English is spoken all over the world.

Not necessarily:

→ English is spoken by people all over the world.

---

# 9. When Should You NOT Use Passive?

If the sentence has **no object**, you generally cannot convert it into passive.

Example:

> He sleeps.

There is no object.

You cannot say:

❌ Sleep is slept by him.

Why?

Because **sleep** is intransitive here.

---

# 10. Transitive vs Intransitive Verbs

This connects directly with your previous grammar topics.

### Transitive verb

A verb that can take an object.

> He kicked **the ball**.

"kicked what?"

→ the ball

So it is transitive.

Therefore, passive is possible:

> The ball was kicked by him.

---

### Intransitive verb

A verb that does not take an object.

> He slept.

Slept what?

Nothing.

So passive isn't possible.

### Common intransitive verbs

* sleep
* arrive
* go
* come
* laugh
* cry
* happen
* die
* occur

Example:

> The baby cried.

No object → no normal passive.

---

# 11. Modal Verbs in Passive Voice

Modal verbs include:

**can, could, may, might, shall, should, will, would, must, ought to**

### Active

**Subject + modal + V1 + Object**

> He can solve the problem.

### Passive

**Object + modal + be + V3**

> The problem can be solved by him.

### Examples

> You should follow the rules.

→ The rules **should be followed** by you.

> They must complete the work.

→ The work **must be completed** by them.

> We can solve this problem.

→ This problem **can be solved** by us.

### Remember:

**Modal + be + V3**

# 12. Imperative Sentences in Passive Voice

First, understand what an **imperative sentence** is.

An imperative sentence is a sentence that gives:

* an **order**
* a **command**
* a **request**
* an **advice**
* an **instruction**

The subject **"you" is usually understood**, even though it isn't written.

### Examples

> Open the door.

The actual meaning is:

> **You** open the door.

> Finish the work.

Meaning:

> **You** finish the work.

> Help me.

Meaning:

> **You** help me.

So imperative sentences are special because the subject **you** is normally hidden.

---

## How do we change an imperative sentence into Passive?

The common structure is:

### Active

**V1 + Object**

### Passive

**Let + Object + be + V3**

That's the main rule.

---

### Example 1

Active:

> Open the door.

Identify:

* Verb → open
* Object → the door

Apply:

**Let + object + be + V3**

open → opened

Therefore:

> **Let the door be opened.**

---

### Example 2

Active:

> Clean the room.

Object:

> the room

V3 of clean:

> cleaned

Passive:

> **Let the room be cleaned.**

---

### Example 3

Active:

> Write a letter.

Passive:

> **Let a letter be written.**

---

### Example 4

Active:

> Complete the work.

Passive:

> **Let the work be completed.**

---

# Negative Imperative

Now suppose the sentence says:

> Do not open the door.

This is a **negative imperative**.

The passive structure is:

### Active

**Do not + V1 + Object**

### Passive

**Let + Object + not + be + V3**

Example:

> Do not open the door.

→ **Let the door not be opened.**

---

### Another example

> Do not waste time.

→ **Let time not be wasted.**

---

# Imperative with "Please"

Sometimes the sentence is a request.

> Please open the door.

You can use:

> Let the door be opened.

Or, depending on the intended meaning:

> You are requested to open the door.

For competitive exams, the exact passive structure can depend on whether the sentence is an **order, request, advice, or prohibition**.

### Useful patterns

| Active meaning | Passive pattern           |
| -------------- | ------------------------- |
| Order          | Let + object + be + V3    |
| Request        | You are requested to + V1 |
| Advice         | You are advised to + V1   |
| Prohibition    | You are forbidden to + V1 |

Example:

> Please help the poor.

→ You are requested to help the poor.

Example:

> Follow the rules.

→ You are advised to follow the rules.

---

# 13. Interrogative Sentences in Passive Voice

Now let's understand **interrogative sentences**.

An interrogative sentence is simply a **question**.

Examples:

> Does he play cricket?

> Did she write the letter?

> Has he completed the work?

> Can they solve the problem?

When converting these into passive, we **keep the sentence as a question**.

The question mark remains.

---

# The Main Rule

You first identify:

1. The tense
2. The object
3. The helping verb required for passive
4. V3 of the main verb

Then arrange them as a question.

---

## Simple Present Questions

Active:

> Does he write a letter?

Break it down:

* Subject → he
* Verb → write
* Object → a letter
* Tense → Simple Present

Normal passive:

**is/am/are + V3**

So:

> **Is a letter written by him?**

Notice something important:

### "Does" disappears.

Why?

Because **is** is now carrying the grammatical structure of the passive sentence.

---

### Example

Active:

> Do they play cricket?

Passive:

> **Is cricket played by them?**

Why **is**?

Because cricket is singular/uncountable.

---

### Example

Active:

> Do they clean the rooms?

Passive:

> **Are the rooms cleaned by them?**

Why **are**?

Because "rooms" is plural.

---

# Simple Past Questions

Active:

> Did he write a letter?

Passive:

> **Was a letter written by him?**

Again, **did disappears**.

Why?

Because passive Simple Past uses:

**was/were + V3**

So "was" carries the past tense.

---

### Another example

Active:

> Did they build the house?

Passive:

> **Was the house built by them?**

---

# Present Continuous Questions

Active:

> Is he writing a letter?

Passive:

> **Is a letter being written by him?**

Remember:

Present Continuous Passive:

**is/am/are + being + V3**

So:

> Is + a letter + being + written + by him?

---

### Example

Active:

> Are they repairing the car?

Passive:

> **Is the car being repaired by them?**

---

# Present Perfect Questions

Active:

> Has he completed the work?

Passive:

> **Has the work been completed by him?**

Rule:

**has/have + been + V3**

---

### Example

Active:

> Have they finished the project?

Passive:

> **Has the project been finished by them?**

---

# Modal Questions

Active:

> Can he solve the problem?

Passive:

> **Can the problem be solved by him?**

Rule:

**Modal + object + be + V3**

---

### More examples

> Should we follow the rules?

→ **Should the rules be followed by us?**

> Can they repair the car?

→ **Can the car be repaired by them?**

---

# 14. WH-Questions in Passive Voice

Now we have questions beginning with:

* what
* why
* when
* where
* who
* whom
* how
* which

These are called **WH-questions**.

Example:

> Why did he break the window?

The question asks **why**.

When converting to passive, **why remains at the beginning**.

---

## Example

Active:

> Why did he break the window?

Object:

> the window

Tense:

> Simple Past

Passive structure:

**Why + was/were + object + V3 + by + subject?**

Therefore:

> **Why was the window broken by him?**

---

### Another example

Active:

> When did they build this bridge?

Passive:

> **When was this bridge built by them?**

---

### Another example

Active:

> How did he solve the problem?

Passive:

> **How was the problem solved by him?**

# 15. "Who" and "Whom" in Passive

This is particularly important for exams.

Suppose:

> Who wrote this book?

Here, **who is the subject**.

Who performed the action?

→ Who wrote it?

When converting to passive, we need to express the doer after **by**.

So:

> **By whom was this book written?**

---

## Why "whom"?

Because after a preposition like **by**, traditional formal grammar uses the **object form**.

Compare:

| Subject form | Object form |
| ------------ | ----------- |
| who          | whom        |
| he           | him         |
| she          | her         |
| they         | them        |
| we           | us          |
| I            | me          |

So:

> Who wrote the book?

→ By **whom** was the book written?

---

# Another example

Active:

> Who broke the window?

Passive:

> **By whom was the window broken?**

---

# But be careful!

Not every "who" becomes "by whom".

Example:

> Whom did he invite?

Here, **whom** is already the object.

Active:

> He invited whom?

Passive:

> **Who was invited by him?**

Here **whom → who** because the object becomes the subject of the passive sentence.

This is an important concept.

---

# 16. Sentences Having Two Objects

Some verbs can take **two objects**.

Example:

> She gave me a book.

There are two objects:

1. **me**
2. **a book**

Why?

She gave **what?**

→ a book

She gave a book **to whom?**

→ me

So there are two objects.

---

# How does passive work with two objects?

You can often make **either object** the subject.

### Active

> She gave me a book.

### Passive 1

> **I was given a book by her.**

Here:

**me → I**

became the subject.

---

### Passive 2

> **A book was given to me by her.**

Here:

**a book**

became the subject.

Both are grammatically possible.

---

# More examples

Active:

> He taught us English.

Possible passive:

> **We were taught English by him.**

or:

> **English was taught to us by him.**

---

Another:

> She sent me a letter.

→ **I was sent a letter by her.**

or:

→ **A letter was sent to me by her.**

---

# Which verbs commonly have two objects?

Some common ones:

* give
* send
* offer
* teach
* tell
* show
* lend
* buy
* bring
* ask

Example:

> He gave me a pen.

> She told me a story.

> They offered him a job.

---

# 17. Prepositional Verbs in Passive Voice

This is a very important concept.

Some verbs naturally occur with a **preposition**.

Examples:

* look at
* laugh at
* listen to
* look after
* talk about
* speak to
* depend on
* rely on
* take care of

When converting these sentences into passive, **the preposition usually stays**.

---

## Example: laugh at

Active:

> They laughed at him.

Verb phrase:

> laughed **at**

Object:

> him

Passive:

> **He was laughed at by them.**

Notice:

❌ He was laughed by them.

Wrong.

The **at** must remain.

---

## Example: look after

Active:

> She looks after the child.

Passive:

> **The child is looked after by her.**

Not:

❌ The child is looked by her.

---

## Example: talk about

Active:

> They talked about the problem.

Passive:

> **The problem was talked about by them.**

The preposition **about** remains.

---

## Why?

Because **look after**, **laugh at**, **talk about**, etc. function as complete verb-preposition combinations.

Removing the preposition changes the construction.

### Exam rule:

> **If the active verb requires a preposition, don't randomly remove it when making passive.**

---

# 18. Passive with "Make"

This is a special construction that frequently appears in grammar questions.

Consider:

> The teacher made him stand.

Structure:

**Subject + made + object + V1**

* Subject → teacher
* Object → him
* V1 → stand

When converting to passive, something interesting happens.

### Active:

> The teacher made him stand.

### Passive:

> **He was made to stand by the teacher.**

Notice:

**stand → to stand**

The word **to** appears.

---

# Rule for "make"

### Active

**make + object + V1**

### Passive

**object + be + made + to + V1**

---

### Example

> The manager made the workers work late.

→ The workers were made **to work** late by the manager.

---

### Another

> The teacher made the students clean the classroom.

→ The students were made **to clean** the classroom by the teacher.

---

# 19. Passive with "See", "Hear", "Watch", etc.

This is another special construction.

Consider:

> I saw him cross the road.

Structure:

**Subject + see + object + V1**

When converted to passive:

> **He was seen to cross the road by me.**

Again, **to** appears.

---

# Rule

With certain perception verbs:

### Active

**see/hear/watch + object + V1**

### Passive

**object + be + V3 + to + V1**

---

### Example

Active:

> I saw him enter the room.

Passive:

> **He was seen to enter the room by me.**

---

### Example

Active:

> We heard her sing.

Passive:

> **She was heard to sing by us.**

# 20. Reporting Verbs

Now we get into a more advanced but important passive construction.

Consider:

> People say that he is honest.

This has two parts:

**People say** + **that he is honest**

This is called a **reporting structure**.

We can convert it into passive in two ways.

---

## Method 1

Make "it" the passive subject.

Active:

> People say that he is honest.

Passive:

> **It is said that he is honest.**

Why?

"People say" becomes:

> It is said

---

## Method 2

Make the person in the reported clause the subject.

> **He is said to be honest.**

This is extremely common in formal English.

---

# Another example

Active:

> People believe that he is innocent.

Passive:

> **It is believed that he is innocent.**

or:

> **He is believed to be innocent.**

---

### Another

Active:

> People think that she is intelligent.

→ **It is thought that she is intelligent.**

or:

→ **She is thought to be intelligent.**

---

# Important reporting verbs

Common verbs used this way:

* say
* believe
* think
* know
* expect
* consider
* suppose
* report
* understand

# 21. "Get" Passive

Normally passive voice uses:

> **be + V3**

Example:

> He was injured.

But English sometimes uses:

> **get + V3**

Example:

> He got injured.

This is called the **get-passive**.

---

### Examples

> She got hurt.

> He got punished.

> They got caught.

> The window got broken.

These all express a passive meaning.

---

# Difference between "be" passive and "get" passive

### Be passive

Usually more neutral/formal:

> He was injured.

### Get passive

Often more conversational and can emphasize that something happened to someone:

> He got injured.

For competitive grammar exams, **be + V3** is much more important.

---

# 22. When Passive Voice Is NOT Possible

This is extremely important.

A normal passive construction requires an **object**.

Why?

Because the object of the active sentence becomes the subject of the passive sentence.

If there is no object, what will become the passive subject?

Nothing.

---

## Example

> He sleeps.

Ask:

He sleeps **what?**

There is no object.

Therefore:

❌ A sleep is slept by him.

No.

---

### Another

> The baby cried.

Cried what?

No object.

Therefore no normal passive.

---

### Another

> He arrived.

Arrived what?

No object.

No normal passive.

---

# 23. Transitive vs Intransitive — Deep Understanding

Since this is directly connected to voice, let's make it very clear.

## Transitive Verb

A transitive verb **takes an object**.

Example:

> He kicked the ball.

Ask:

**He kicked what?**

→ the ball.

Therefore:

**kick = transitive**

Because it transfers the action to an object.

Passive:

> The ball was kicked by him.

---

## Intransitive Verb

An intransitive verb **does not take an object**.

Example:

> He slept.

Ask:

He slept what?

No answer.

Therefore:

**sleep = intransitive**

No normal passive.

---

# Important: The Same Verb Can Sometimes Be Transitive or Intransitive

This is an important higher-level concept.

Example:

> He opened the door.

"opened what?"

→ the door.

So **opened = transitive**.

Passive:

> The door was opened by him.

But:

> The door opened.

Here there is no object.

So **opened = intransitive** in this sentence.

Therefore, whether a verb is transitive/intransitive can depend on **how it is used in the sentence**.

---

# 24. "By" Is Not Always Required

In passive voice, we often use:

> by + doer

But it is **not compulsory**.

Consider:

> Someone stole my phone.

Passive:

> My phone was stolen.

We don't need to say:

> My phone was stolen by someone.

Why?

Because "someone" isn't important.

---

## When do we usually omit "by + subject"?

When the doer is:

* unknown
* obvious
* unimportant
* general

---

### Example

> People speak English all over the world.

→ English is spoken all over the world.

Who speaks it?

People.

That's obvious/general, so we don't need "by people."

---

### Example

> Someone broke the window.

→ The window was broken.

We don't know who.

---

### Example

> The police arrested the thief.

Here the police are important.

→ The thief was arrested **by the police**.

---

# 25. Active and Passive with "By"

A common misconception is:

> Passive voice MUST contain "by."

No.

That's false.

### Passive:

> The window was broken.

There is no "by."

It is still passive because:

**window = receiver of action**

---

# 26. Don't Change the Tense

This is probably the **#1 mistake** students make.

Suppose:

> They are repairing the car.

This is **Present Continuous**.

Passive must remain Present Continuous.

Correct:

> The car **is being repaired** by them.

Not:

> The car was repaired by them.

That changes the tense to Simple Past.

---

### Another example

Active:

> She has completed the work.

Tense:

Present Perfect.

Correct:

> The work **has been completed** by her.

Not:

> The work was completed by her.

---

# 27. Don't Change the Meaning

Voice conversion should change **the structure**, not the meaning.

Active:

> The boy broke the window.

Meaning:

The boy performed the breaking.

Passive:

> The window was broken by the boy.

Same event.

---

# 28. Pronoun Changes

When the subject moves after **by**, change the pronoun to the object form.

### Remember this table

| Active subject | After "by" |
| -------------- | ---------- |
| I              | me         |
| we             | us         |
| you            | you        |
| he             | him        |
| she            | her        |
| it             | it         |
| they           | them       |

---

### Examples

> She wrote the letter.

→ The letter was written by **her**.

> He repaired the car.

→ The car was repaired by **him**.

> They completed the project.

→ The project was completed by **them**.

> We solved the problem.

→ The problem was solved by **us**.

---

# 29. "By" vs "With"

This is another useful distinction.

### By = person/agent who performs the action

> The letter was written **by John**.

John is the doer.

### With = instrument/tool used

> The letter was written **with a pen**.

Pen is the instrument.

---

### Example

> He cut the cake with a knife.

Passive:

> The cake was cut by him **with a knife**.

So:

**by → doer**

**with → instrument**

---

# 30. Passive Voice with Modal Auxiliaries

Let's understand this properly.

Modal auxiliaries:

* can
* could
* may
* might
* shall
* should
* will
* would
* must
* ought to

After a modal, normally use **V1**:

> He can solve the problem.

Not:

❌ He can solves the problem.

---

## Passive Rule

**Modal + be + V3**

---

### Can

Active:

> He can solve the problem.

Passive:

> The problem **can be solved** by him.

---

### Should

Active:

> You should follow the rules.

Passive:

> The rules **should be followed** by you.

---

### Must

Active:

> They must complete the work.

Passive:

> The work **must be completed** by them.

---

### May

Active:

> They may cancel the match.

Passive:

> The match **may be cancelled** by them.

---

# 31. "Ought to"

"Ought to" is slightly different because it already contains **to**.

Active:

> You ought to follow the rules.

Passive:

> The rules ought to be followed by you.

Structure:

**ought to + V3**

---

# 32. Passive Voice with "Have to"

"Have to" expresses necessity.

Active:

> You have to complete the work.

Passive:

> The work has to be completed by you.

Notice:

**have to + V1**

becomes:

**has/have to + be + V3**

---

# 33. Passive Voice with "Need to"

Active:

> You need to complete the work.

Passive:

> The work needs to be completed by you.

---

# 34. Passive Voice with "Used to"

Active:

> People used to grow rice here.

Passive:

> Rice used to be grown here.

Structure:

**used to + be + V3**

# 35. Passive Voice — Complete Mental Process

When you get an Active → Passive question, don't randomly change words.

Use this process:

### Step 1 — Find Subject

Who performs the action?

### Step 2 — Find Verb

What action is happening?

### Step 3 — Find Object

What receives the action?

### Step 4 — Identify Tense

Is it:

* Simple Present?
* Present Continuous?
* Present Perfect?
* Simple Past?
* Past Continuous?
* Past Perfect?
* Simple Future?
* Modal?

### Step 5 — Move Object

Object becomes the new subject.

### Step 6 — Use the correct passive helping verb

### Step 7 — Convert main verb → V3

### Step 8 — Add "by + old subject" if needed.

---

# Let's Apply Everything

Take:

> The students are solving the problem.

### Step 1

Subject:

> the students

### Step 2

Verb:

> are solving

### Step 3

Object:

> the problem

### Step 4

Tense:

Present Continuous

### Step 5

Object moves:

> The problem...

### Step 6

Present Continuous passive:

> is/am/are + being

Problem = singular:

> is being

### Step 7

solve → solved

### Step 8

Add doer:

> by the students

Final:

> **The problem is being solved by the students.**

That's the complete process.

# 36. The Most Important Rules You Should Memorize

If you're preparing for verbal ability, these are the rules I would prioritize.

### Rule 1

**Passive always uses V3.**

> written, eaten, done, taken, made

---

### Rule 2

The **object of Active** usually becomes the **subject of Passive**.

> He wrote **a letter**.

→ **A letter** was written by him.

---

### Rule 3

Don't change the tense.

---

### Rule 4

Continuous Passive contains:

> **being + V3**

---

### Rule 5

Perfect Passive contains:

> **been + V3**

---

### Rule 6

Modal Passive contains:

> **modal + be + V3**

---

### Rule 7

No object → normally no passive.

---

### Rule 8

Imperative:

> **Let + object + be + V3**

---

### Rule 9

Prepositional verbs keep their preposition.

> He laughed **at** me.

→ I was laughed **at** by him.

---

### Rule 10

"make + object + V1" becomes:

> **object + be + made + to + V1**

---

### Rule 11

With reporting verbs:

> People say that he is honest.

→ It is said that he is honest.

or:

→ He is said to be honest.

---

### Rule 12

"by" tells you the **doer**.

"with" tells you the **instrument**.

## The simplest way to think about Voice

Don't try to memorize hundreds of separate sentences.

Think:

**ACTIVE**

> **Who does → what?**

**PASSIVE**

> **What receives → what is done → by whom?**

For example:

> **The teacher teaches English.**

Who does the action? → **teacher**
What receives the action? → **English**

So:

> **English is taught by the teacher.**

Once you can identify **Subject + Verb + Object + Tense**, the passive conversion is mostly just applying the correct formula.
