# What is a Part of Speech?

A **Part of Speech** is the **role or function** a word performs in a sentence.

For example:

> **Harsh studies English every day.**

Let's identify each word.

| Word    | Part of Speech | Why?                |
| ------- | -------------- | ------------------- |
| Harsh   | Noun           | Name of a person    |
| studies | Verb           | Action              |
| English | Noun           | Name of a subject   |
| every   | Adjective      | Describes "day"     |
| day     | Noun           | Thing (time period) |

Notice something interesting.

The same word can have different jobs depending on the sentence.

Example:

> I **work** every day.

Here, **work** is a **verb**.

But:

> My **work** is difficult.

Now **work** is a **noun**.

So **parts of speech depend on how the word is used**, not just the word itself.

# Why Should You Learn Parts of Speech?

Imagine trying to build a house without knowing the purpose of:

* Bricks
* Cement
* Steel
* Windows

You'd struggle.

Grammar is similar.

You need to know:

* Which words name things
* Which words describe
* Which words show actions
* Which words connect ideas
* Which words replace nouns

Only then can you build correct sentences.

# The 8 Parts of Speech

There are **eight main parts of speech** in English.

| Part         | Job                                                |
| ------------ | -------------------------------------------------- |
| Noun         | Names a person, place, thing, or idea              |
| Pronoun      | Replaces a noun                                    |
| Verb         | Shows action or state                              |
| Adjective    | Describes a noun                                   |
| Adverb       | Describes a verb, adjective, or another adverb     |
| Preposition  | Shows relationships (place, time, direction, etc.) |
| Conjunction  | Joins words or sentences                           |
| Interjection | Expresses emotion                                  |

We'll study each one separately.

# How They Work Together

Look at this sentence:

> **The intelligent student answered the difficult question carefully because he had prepared well.**

Let's break it down.

| Word         | Part of Speech                                                                |
| ------------ | ----------------------------------------------------------------------------- |
| The          | Article (a type of determiner, often taught with adjectives in basic grammar) |
| intelligent  | Adjective                                                                     |
| student      | Noun                                                                          |
| answered     | Verb                                                                          |
| the          | Article                                                                       |
| difficult    | Adjective                                                                     |
| question     | Noun                                                                          |
| carefully    | Adverb                                                                        |
| because      | Conjunction                                                                   |
| he           | Pronoun                                                                       |
| had prepared | Verb                                                                          |
| well         | Adverb                                                                        |

Every word has a specific job.

# Imagine a School

This analogy helps many people remember the roles.

🏫 A school needs different people.

* Students → Nouns
* Teachers doing work → Verbs
* School uniforms → Adjectives (describe)
* School rules connecting everyone → Conjunctions
* Directions like "to the library" → Prepositions
* "Wow!" when someone wins → Interjections

Each has a different responsibility.

# A Sentence Is Like a Team

Consider:

> **The small dog ran quickly into the garden.**

| Word    | Job         |
| ------- | ----------- |
| The     | Article     |
| small   | Adjective   |
| dog     | Noun        |
| ran     | Verb        |
| quickly | Adverb      |
| into    | Preposition |
| the     | Article     |
| garden  | Noun        |

Everything has a role.

# The Most Important Rule

**Never memorize only the definitions.**

For example:

"Noun = person, place, thing."

That's true, but it's not enough.

Instead, ask yourself:

> **What job is this word doing in this sentence?**

That question will help you identify parts of speech much more accurately.
